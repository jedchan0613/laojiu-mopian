注册模块界面原型目录

这份原型用来核对注册登录、我的投稿、我的收藏、账户设置和上传流程的版式与文案，全部使用假数据，只在本机管理入口内查看。

边界说明（先看这里）

· 不发送验证码、不发邮件、不接收真实投稿，所有操作只在浏览器里演示；

· 不读取真实档案、真实用户资料或私密收件区，页面里的题目、状态和图片都是示例；

· 只放在本机私有预览地址，不进入公开网站构建，也不会部署到线上；

· 「模拟登录」和学习用的演示按钮只改变本机浏览器里的一份假状态，可随时用「重置演示数据」清空。

异常与边界状态在哪里看

· 登录：验证码过期 / 输入错误 / 尝试次数过多 / 60 秒内重复发送 / 邮件服务不可用 / 已注册用户直接登录 —— 登录页底部「原型演示控制」。

· 我的投稿：加载中骨架屏、空列表、站主说明、已公开链接、暂不采用理由 —— 列表页底部「原型演示控制」。

· 投稿详情：待补充、草稿、已公开三种场景切换，含“修改审核中”“撤下处理中”附加提示 —— 详情页底部。

· 我的收藏：全部取消后的空状态、已撤下档案“暂不可查看”—— 收藏页内直接操作。

· 账户设置：退出全部设备确认、导出与注销申请回执说明、敏感操作重新验证提示 —— 设置页底部。

· 上传：格式不符 / 单张超 5 MB / 合计超 20 MB / 重复图片 / 一次选 9 张 / 部分上传失败可重试 / 保存失败 / 配额已满 / 登录状态过期 / 服务维护中 —— 上传页底部。

怎么打开、怎么重置

1. 双击项目根目录的 启动档案管理.cmd，保持黑色窗口开启。

2. 管理页打开后，点击左侧「预览 → 注册模块预览」，或直接访问 http://127.0.0.1:4173/admin/preview/。

3. 页面上方的深色工具条可以「模拟登录 / 退出演示登录」「重置演示数据」「返回档案管理」。

4. 原型里的“保存草稿”等操作只演示反馈，不会写入任何真实数据；重置后一切回到初始假数据。

本原型暂不包含

· 真实邮箱验证、真实会话与权限校验（需要先确认技术定案和新增依赖，见《注册模块阶段一：现状核对与技术定案》文档）；

· 站主管理端的账户相关功能（账号状态、邮箱恢复、导出与注销处理等，属于后续阶段）；

· 评论、私信、关注、公开个人主页、头像上传等方案明确排除的内容。

原型演示控制（仅本地）

重置会清空本机浏览器里的假登录状态、收藏与草稿时间，不影响任何真实档案或投稿数据。
