# 公开点赞服务

该目录提供公开档案点赞所需的最小服务。它只使用 Node.js 自带能力，不安装数据库或第三方依赖。

## 数据边界

- 点赞以档案永久编号为单位，不以页面展示位置或单张图片为单位。
- 同一访问地址对同一件档案只计一次。
- 服务不保存原始 IP；只保存由服务器密钥生成的不可逆验证摘要。
- 摘要只能用于判断“这个访问地址是否已经赞过这件档案”，不能还原原始 IP。
- 点赞文件必须放在公开网站目录之外。
- 共享同一个公网地址的家庭、单位或校园网络会被视为同一访问地址；访问地址变化后可能再次计数。这是无账号方案的固有限制。

## 接口

- `GET /api/likes?items=永久编号,永久编号`：一次读取最多 20 件档案的点赞数和当前访问者状态。
- `POST /api/likes/永久编号`：新增一次点赞；重复请求返回当前结果但不增加计数。
- `GET /healthz`：服务健康检查。

服务只能监听 `127.0.0.1:4175`，由公开网站的 Caddy 反向转发 `/api/likes`。Caddy 必须覆盖 `X-LJM-Client-IP` 请求头，不能直接把该端口开放到公网。
