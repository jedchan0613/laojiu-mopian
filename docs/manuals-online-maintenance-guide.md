# 线上说明书维护使用说明

适用范围：7.5部署并明确开放后，使用原来的管理员账号进入管理工作台。普通网站账号没有维护权限。

## 第一次进入

1. 打开管理页，在左侧选择“说明书维护”；手机上先展开工作区菜单。
2. 核对页面显示的模式和状态。若提示“维护尚未开放”，联系维护者检查开关，不需要反复保存或更换登录账号。
3. 仅当页面明确提示“首次建立维护记录”，而且正式说明书目录确实为空时，勾选确认后保存第一份目录草稿。若提示已有公开资料却缺少私密记录，应停止操作并恢复记录，不能建立空目录覆盖。

## 整理和保存

先整理品牌，再整理准确型号，最后添加说明书。尽量填写完整型号、语言、用途、版本、完整程度和来源；缺项可先保存草稿，发布前仍须补齐。

两种资料分别处理：官方来源索引填写已人工核实的官方网址；网站自藏资料只关联已通过入站检查并获准公开的档案发布副本。不要把原始扫描件、源PDF或待审核图片放进这里。提供网址不会让服务器自动下载文件。

点击“保存目录草稿”只保存私密记录，不改变访客网站。确认保存成功后再离开；提示版本冲突时先核对其他页面的最新内容，不反复覆盖。编辑页未保存的输入不等于已保存草稿。

## 预览和发布

1. 保存后打开草稿预览，核对品牌、型号、版本、页序及图片；预览仅管理员可见。
2. 草稿或关联档案变化后，旧预览可能失效，返回维护页重新打开即可。
3. 点击“发布前检查”，逐项检查来源、隐私、权利及资料质量，阅读整个目录的变更范围，再完成页面要求的人工确认。
4. 执行正式发布并等待结果。系统完成构建和网站切换、返回成功回执后，资料才公开；通过“查看说明书库”前往真实访客域名复核。

若发布较久、断网或刷新后结果不明确，先用页面的操作查询核对。不要另开页面再次发布同一操作。“请求停止”须等待服务器确认；不能仅凭浏览器关掉了就认定发布取消。

## 撤下和恢复

撤下前查看影响并填写原因。撤下说明书目录引用不会删除原档案和图片，也不会自动撤下原档案本身。

恢复历史只生成新的私密草稿，当前草稿会先得到可恢复保留。恢复后重新检查和发布，才会再次对访客生效；历史目录不等于每个历史网站版本永久留存。

## 遇到提示时

| 提示 | 应怎么做 |
| --- | --- |
| 有其他发布任务正在运行 | 等待任务完成，先查原操作结果，不重复提交 |
| 当前目录版本已更新 | 重新读取并核对，避免覆盖其他页面的修改 |
| 预览失效或图片暂时不可读 | 返回维护页重新打开；保留页码，仍失败时交维护者核对 |
| 需要核对、中断事务、记录与公开目录不一致 | 停止写入，保留操作编号，请维护者核对；不要清空目录或手工删除事务 |
| 保存成功但访客网站未变化 | 草稿不会自动公开，继续预览、检查和正式发布流程 |

说明书专用投稿审核、整册转入和PDF交接仍按独立阶段安排。维护开关只接通目录维护；不代表PDF已经开放。
