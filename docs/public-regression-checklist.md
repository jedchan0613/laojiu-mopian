# 公开网站固定回归检查

这份清单用于防止首页、档案列表和详情页在后续修改中再次出现重复藏品、空内容区块、异常长图、横向溢出或管理端内容混入公开目录等问题。

## 一、每次正式构建自动检查

在 `site/` 目录运行项目现有的正式构建命令：

```powershell
npm run build
```

构建完成后会自动执行公开页面检查。以下任一情况出现时，构建会明确报错：

- 首页精选档案缺失、重复，或与下方其他档案重复。
- 首页、档案列表或详情页缺少与永久编号一致的唯一点赞入口，或点赞程序没有接入。
- 档案列表数量与实际公开详情页数量不一致。
- 排序控件或规定的四种排序方式缺失。
- 详情页缺少资料状态、引用入口或档案结构化信息。
- 信件阅读模板缺少 `LET` 类型判断、文字阅读、原件对照、只看原件或原件核对说明。
- 详情页出现完全空白的内容区块。
- 公开图片没有声明宽度和高度，可能引起页面跳动或异常拉长。
- 公开规范网址包含 `localhost` 或 `127.0.0.1`。
- 管理页面、管理接口或管理端标记进入 `site/dist/`。
- 未配置正式域名时错误生成站点地图；配置后又没有生成站点地图。

已经构建完成时，可以单独重新执行：

```powershell
npm run check:public
```

## 二、固定桌面检查

使用 `1280 × 720` 视口依次检查：

1. 首页 `/`：只有一件首屏精选；下方其他档案不重复；页面没有横向溢出。
   点赞接口正常时，每件展示档案显示一个点赞按钮和数字；重复点击同一件档案不增加数字；接口异常时不显示失效按钮。
2. 档案页 `/archive/`：搜索、分类、排序和更多筛选对齐；四种排序改变后顺序正确；筛选与排序可以同时保留在网址中；每件档案的点赞按钮与详情链接互不遮挡。
3. 一件多图详情：主图、缩略图和放大查看没有异常拉长；标题下方点赞入口正常；空故事区块不显示。
4. 一件普通详情：点赞数与首页、列表中的同一档案一致；资料状态、基本信息、引用与分享、上一件／下一件顺序清楚；复制按钮有成功或失败提示。
5. “关于”页：五部分说明完整，研究与未知的锚点可以直接定位。
6. 若已有公开信件：默认显示电子文字，三种阅读模式切换正常；正文保留换行，原件只出现一次，没有与下方“故事与原文”重复。

## 三、固定手机检查

使用 `390 × 844` 视口重复检查首页、档案页和一件详情：

- 页面内容宽度不超过手机可视宽度，没有左右拖动。
- 点赞按钮不遮挡图片、档案标题或“查看档案”入口，触控区域完整。
- 搜索、分类、排序和更多筛选改为单列，不发生文字或按钮重叠。
- 详情页资料状态与引用区改为单列；两个复制按钮可完整点击。
- 图片保持正常比例，缩略图不会被拉成长条，放大层可以关闭。
- 本地预览工具条收起时不遮挡正文，展开后页脚仍可完整滚动查看。

## 四、正式域名检查

正式域名确定后，在构建环境配置 `PUBLIC_SITE_URL`。构建会自动生成 `sitemap.xml`，并在 `robots.txt` 中加入正式站点地图地址；本机地址和无效协议会被拒绝。

回归检查只读取公开构建结果，不修改档案 JSON、发布图片、草稿、历史版本或回收区。
