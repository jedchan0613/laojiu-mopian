本地功能及验收已完成：整册确认、PDF提交快照、纸面页码、同编号整份替换补充、只读历史版本、21项人工审核及旧审核失效检查。2026年11月12日续做补齐实际浏览器操作及320／390／1280宽度外观复检，并修复页码保存后的错误提示。实际200页合成PDF通过转换、逐页标记核对、送审与审核接口及浏览器末页阅读。首次浏览器连接受阻作为历史情况保留在开发日志，本次续验已通过。

本轮没有真实资料入站、公开发布、Git提交／推送或线上部署。PDF整理发布衔接仍属于6.5，本次没有启动。

## 投稿人怎样使用

1. 先保存其他页面的工作，关闭旧的本地启动窗口，再双击根目录`启动档案管理.cmd`。进入“说明书 → 提供说明书”，或从“我的 → 我的投稿”打开原PDF草稿。日常入口仍为`http://127.0.0.1:4173/manuals/contribute/`，4236样例预览没有账号保存与送审能力。本轮没有启停日常4173服务。
2. 按6.2、6.3的步骤私密上传并生成当前PDF整册。旧预览仍可阅读；旧处理配置或缺少本阶段送审检查报告的预览，需要按当前配置重新生成，不能直接沿用。
3. 点击“预览整册”逐页对照。源PDF的页数、页序、方向和内容固定；可以在“纸面页码与本页说明”选择源页面，填写纸上印的页码及本页说明，再点击“保存本页页码与说明”。页码可留空，不推测封面与正文的对应关系。整册缺页仍填写上方“缺页说明”。
4. 保存全部文字与页码后，在“提交审核”逐项阅读并确认3项PDF整册说明和4项原有副本／权利／隐私／私密处理说明。每次读取或保存都会重置勾选，不默认同意。确认绑定当前保存版、源PDF、处理配置、整册图像、纸面页码和文字信息。
5. 点击“确认提交审核”。服务器重新核对源PDF及全部页图，成功后保存只读提交版本，状态进入“已提交，待核对”。这一步不会公开，也不会开放原PDF下载。
6. 从“我的 → 我的投稿 → 查看投稿进度”查看反馈。需要补充时点击“按要求补充”，仍使用原编号；上传补齐后的整份PDF，重新生成、阅读和确认。首版不在PDF中混加图片、删页、换序或单独替换某一张图。
7. 在“已提交版本”选择历史提交，可查看当次文字和阅读当次图片。旧PDF、旧页图和快照私密保留；新草稿及新生成结果不会覆盖它们。保留最近20次提交记录，列表淘汰不自动删除底层文件。
8. 网络结果不明时使用对应的“核对并重试”按钮。系统先查原操作回执；已保存时找回原结果，不重复送审或重复保存页码。页码校验失败会保留填写并解除待核对状态，方便修改。

仅提供官方来源时继续另建“官网线索”草稿，只填写公开入口与依据。已有PDF方式的草稿保持原方式，不能直接改为官网线索或图片方式。官网线索不抓取远程PDF、不带页面送审、不自动升级站内阅读或下载范围。

## 维护者怎样审核

1. 从本地工作台进入“投稿审核”，筛选“说明书投稿”，打开“说明书专用审核”。选择要查看的提交版本；历史提交只读，保存审核必须回到最新提交。
2. PDF“文件处理与版本”区域展示当次私密文件名、大小和摘要、工具版本、配置、检查时间、页数、旋转标记及加密／脚本／表单／附件结果。处理提示保留，不以“已生成”代替逐页核对。
3. 在逐页阅读区对照源PDF页序、纸面页码与本页说明。增加“原尺寸查看／适宽查看”，图片放大后的滚动限定在阅读区。
4. 可以要求补充或暂不采用，并填写给投稿人的说明；内部备注只给维护者。通过PDF阅读副本审核时，必须填写型号、来源及权利三个依据，逐项完成4项说明书检查、4项PDF补充检查、13项隐私检查，共21项，没有全选捷径。
5. 保存通过前，再检查当前记录版、提交版、源PDF、配置和全部JPEG。新文件、新配置、新页图、纸面页码或快照变化均不能沿用旧审核。对已通过的记录重新读取时也检查实际页图；发现绑定问题会提示“旧PDF审核已失效，需重新核对”。
6. PDF通过后停在“初审通过，待整理”。本阶段隐藏PDF的整理交接表单，接口也明确拒绝转入，等待6.5。原图片投稿与官网线索的5.4整理能力继续保留；本轮未执行任何真实交接或发布。

遇到真实人物、私人号码、地址、签名、医疗等内容时仍按既有隐私规则停下，交由资料所有人判断。21项技术表单不会替代人工隐私判断或真实公开授权。

## 快照、失效与隔离

| 情况 | 实际处理 |
| --- | --- |
| 当前PDF没有完整预览／检查报告 | 保留草稿及旧预览，禁止送审，提示重新生成 |
| 更新纸面页码或文字 | 保存版增加、旧整册确认凭证失效，重新读取后所有勾选清空 |
| 新源或新处理配置 | 必须完整生成新册，再创建新的提交快照；旧审核不复用 |
| 要求补充／撤回 | 在原编号回到草稿，清空当前同意声明，移除旧审核绑定；历史快照保持只读 |
| 停止草稿 | 释放草稿名额；完整源文件、图片和提交历史继续私密留存并计入容量 |
| 已有整理标记后申请停止 | 保留申请与关联记录，阻止继续审核；不能借撤回改写正在整理的资料 |
| 文件、页序或快照被改动 | 拒绝提交／通过审核；历史图片也须符合该版留存摘要才能读取 |
| 上传／生成暂停 | 已有版本、回执、阅读和停止仍可使用；新上传、生成、页码保存和送审受开关控制 |
| 工具或配置暂不可核对 | 暂停新送审及通过审核，旧历史图片仍按留存摘要只读读取 |
| 生产模式 | PDF送审与页码能力版本为0；PDF新提交与新写入被拒绝，普通图片投稿不受此能力开关影响 |

私密提交快照固定保存说明书信息、同意声明、源文件标识／摘要／大小、工具及处理配置、结构检查报告、全部页序与逐页JPEG摘要。确认凭证还绑定提交前的记录版号，撤回后即使内容相同也要重新确认，不能拿旧凭证配新操作。

投稿人版本接口使用明确字段列表，只返回本人所需的文字、页面、同意记录及简明PDF版本摘要，不返回内部PDF快照对象、完整检查报告、执行路径、进程号或审核内部备注。6.2本人上传回执仍保留文件摘要，用于核对原上传与重传；新版本摘要不复制内部源绑定。维护者接口仍只在本机工作台开放。

原PDF不进入网站目录，没有公开或账号下载入口；本人及审核页面使用受保护的JPEG接口，禁止缓存且逐次核对账号归属／具体提交版本。静态页面、脚本及公开JSON不保存测试账号、私密编号、源文件摘要、报告或工具配置值。

继续沿用200页、单份PDF20 MiB、单页5 MiB与800万像素、每册历史图片累计100 MiB／1000份、账号200 MiB及现有服务总量。没有新增数据库、Node包、云服务或后台。系统隔离执行器与固定工具包沿用6.3，私密生成报告仅增加已核实的结构、几何和提示记录，不收集PDF作者、标题、批注正文或原始工具诊断。
