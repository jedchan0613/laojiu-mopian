# 相册浏览入口与逐件计数

日期：2026-10-15。状态：本地实现与验收完成；所有人已明确批准上线，正在合并当前生产版本并部署。

## 已确认的展示规则

所有人选择默认将同册档案收拢成相册卡片，进入相册后查看各件；没有归册的档案继续逐件展示。同时明确：“归集计算档案个数的时候，还是按照逐件数计算。”

归集只改变浏览方式，不合并档案记录，不修改永久编号、相册归属、年代地点、发布或隐私状态。55件照片档案加1件相册总档案仍计56件；99幅照片是附件数量，不能代替档案件数。

## 公开网站

- 首页新增“按相册浏览”和“查看全部相册”入口，册卡展示公开题名、图片、档案件数、照片档案数及附图数。首页精选和继续浏览将同册成员合为一个入口，指向相册页；分类计数及“随手翻一件”仍沿用真实单件数据。
- 档案目录默认“相册与单件”，另提供“仅看相册”和“逐件查看全部档案”。使用现有目录的`view=albums`与`view=items`参数，不新增服务或依赖。
- 搜索、分类、年代、地点与标签先在每件档案上匹配，再归集结果。不将甲照片的年代与乙照片的地点拼成一次命中。
- 筛选后册卡分别注明当前命中件数和册内公开总件数，并提供命中分件链接。进入相册查看完整册内公开内容；返回保留浏览方式、条件和页码。
- 总件数始终来自逐件命中结果，分页以实际展示入口计算。当前公开164件，默认显示1本相册和108个未归册单件入口（合计109个入口）；仅看相册为56件、1本，逐件模式仍为164件。
- 继续沿用ACT/G/U3门禁。总册未公开时，不读取其题名、简介或图片，使用公开照片降级形成入口；没有总档案、空册、无图片和未知年代均有说明。
- 中英文界面均适配；档案文字仍遵守现有独立译文状态，未完成的译文保留中文。另一会话的泰语建设未混入本阶段。

## 维护页面

- 档案列表默认“按册归集”，另有“仅看相册”和“逐件查看”。册卡展示本册总件数、当前命中件数、照片档案数与草稿提示。
- 进入册卡后展示全册，返回时恢复进入前的搜索、筛选及页码；册内仍可继续筛选。总档案在前，照片按已有原始位置解析排序。
- 提供“查看总档案”“新增同册照片”及“返回总览”。归集导航不重开当前记录，保留尚未保存的原文、图片及译文；打开另一件继续使用原有未保存提醒。
- 草稿改册保存后，即使记录已退出当前册的筛选，编辑器仍保留刚保存的档案并明确提示去向。新建同册照片沿用既有草稿与隐私门禁；重复总档案时禁止任意选一条作为新增来源。
- 正常与撤销分区分别归集；撤销保持只读。维护库按永久编号合并正式记录和草稿，同一件不重复计数，维护数量不冒充公开数量。
- 沿用现有PHO/ALB归集范围；其他类型的历史相册字段保留，档案仍可逐件找到，不自动迁移资料。
- 手机使用页面自然滚动，修复筛选与册内页头将档案列表挤成几像素、与编辑区重叠的问题；移动端也保留件数提示。资源版本参数避免更新后沿用旧脚本和样式。
