# 第三批第④项：加载优化验收（2026-10-18）

状态：已完成本地开发、Windows及Linux隔离验证，未上线。①②③的既有改动保留；没有推送main、应用缓存配置或改写线上业务数据。

## 完成内容

- 将构建端完整字典、路径规则与浏览器文案分离。每页只携带当前语言消息包，中文不携带翻译字典；消息先就绪再绑定依赖它的功能。参数、访客文字、原文转录不作二次翻译。消息损坏时显示可读提示并停用表单，普通链接保留。
- 检索字段不删减，六语言共用一个构建时生成、内容摘要命名的静态JSON。它不是后台搜索服务，没有新依赖、分页网址或数据权限。文件未准备好时不开放检索；失败不假装“没有结果”。再次部署或资料变化会生成新版本。
- 目录只为当前分页展开完整卡片，其余保留轻量普通链接；切页会收起旧卡片，避免浏览后累积全部完整DOM。仍是每页12个浏览入口，保持相册归并、真实逐件计数、排序、检索高亮和返回状态。
- 动态卡片只使用DOM安全创建和textContent；继承Astro样式作用域，不把档案文字当HTML。补上逐件模式12页页码在小屏的换行，未改首页轮播规则。
