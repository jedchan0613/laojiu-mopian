# 中英文网站使用与验收记录

日期：2026-10-14。状态：本轮双语改造已完成并正式上线。

## 访问和使用

- 中文首页：https://laojiumopian.com/ 。旧网址继续默认显示简体中文。
- 英文首页：https://laojiumopian.com/en/ 。页面右上角可以选择“简体中文 / English”。
- 同一档案的中英文共用永久编号；切换语言后仍停留在同一档案，列表中的搜索、筛选和排序参数继续保留。
- 108 件公开档案已配套英文题名、简介、地点及其他公开说明，共 876 个文本字段、199 条图片说明。代码标签和各类型维度名称也提供英文显示。
- 图片中的文字和档案原文转录保持原语言。本轮没有把信件、日记等原文全文译成英文；英文页面明确显示“Original text · English translation pending”，已经翻译的简介与原文分开呈现。
- 登录、收藏、投稿、联系与纠错等既有功能提供英文界面。账号设置可以选择通知语言；验证及进度邮件沿用原邮件服务，按对应语言使用模板。

## 以后如何维护英文

1. 在现有档案管理入口打开已经公开的档案，选择“英文内容”。
2. 对照每个中文来源填写英文，点击“保存英文草稿”。草稿只留在维护区。
3. 可选择“保存并标记待审核”，通过“查看英文草稿预览”切换中英核对。原文译文须明确选择全文翻译或摘要。
4. 逐项核对事实、未知与待考表述、图片说明和脱敏范围，勾选确认后点击“审核并发布英文”。系统执行正式构建，失败时保留原有效版本。
5. 中文来源发生变化时，相关英文自动标为需要复核。刷新中文来源，修改并确认对应字段后再次发布；没有变化的英文仍可使用。

新入站档案仍先走现有字段、图片、隐私和正式发布检查。英文维护只接受已公开档案及允许公开的字段，不绕过入站规则。

## 实现边界

- 沿用 Astro、Node、现有服务器和依赖锁文件，没有新增依赖包、数据库服务或第三方翻译平台。
- 中文是现有档案事实来源，译文独立存储。年代数值、分类代码、图片、关联、收藏和点赞继续共用原数据。
- 维护译文在私密数据根目录的 `translations/` 中，包含草稿、审核及逐字段来源指纹；公开构建只生成有效英文展示值。管理记录不进入公开目录。
- 中文内容更新后，失效英文从有效展示层移除；未达到完整发布条件的英文详情显示待复核提示，设置 `noindex`，且不进入英文站点地图。已达标的中英文页提供各自规范网址及语言对应关系。
- `/en/` 使用独立错误页；账号入口的禁止收录规则覆盖两种语言。资源、下载及 API 地址保持共用。
