# 说明书 9.3 药品查询、投稿审核与发布

2026 年 11 月 19 日完成本地开发和验收。测试使用虚构药品、企业、账号和页图。范围见[药品独立维护设计](manuals-medicines-design.md)。

## 如何使用

| 使用者 | 入口和操作 | 得到的结果 |
| --- | --- | --- |
| 读者 | 进入「说明书」，在品类中选「药品」，可输入通用名、旧称、商品名、企业或规格 | 同名药品按剂型、规格和企业分别展示。打开对应版本，可以阅读已审核页图或前往该版本的官方来源 |
| 投稿人 | 打开「提供说明书」，选择「药品」，按资料原文填写药名或原件题名，再填写剂型、规格、企业和版本来源 | 可保存后继续编辑，提交时保留该次资料。只有历史题名时也能投稿 |
| 审核员 | 打开该份投稿，核对身份、规格、企业、版本与来源，再明确选择已有药品或新建药品 | 一版适用于多个规格时，可选择多条已有药品。转入后得到私密目录草稿，成功回执可直接打开对应版本 |
| 目录维护者 | 核对草稿后打开发布检查，分别展开「药品说明书」与「物件说明书」的新增、修改和撤下清单 | 完成确认后整份目录一次发布。更正规格时可看到受影响的新旧版本。可单独撤下一个版本，恢复历史会先生成草稿 |

## 已验证的场景

- 同名的两种规格可分别查找。两条药品共用一份原文时，在各自的结果中可见，说明书总数只计一次。详情和历史版保留各自的官方来源、阅读页序和原件日期。
- 对已人工确认关联、且两侧均有公开版本的旧型号与独立药品，查询合并显示，详情可在新旧版本间跳转。旧品牌入口、旧品类锚点和详情地址可继续使用。仅在私下整理、尚无公开版本的药品不会随旧资料出现。
- 投稿可在手机宽度下保存、重开、提交。审核员分别走通了新建药品，以及按规格选择已有同名药品两条路径。过期的目录版本和不存在的候选会被拒绝，刷新后可继续。来自已审核投稿的版本会显示只读的适用药品清单。
- 同一份目录混合维护物件和药品，能逐类检查发布影响。仅修改内部备注不会产生公开变更。公开输出按允许字段生成，不带私密投稿编号、审核备注和未关联公开说明书的药品资料。发布构建失败、单版撤下和历史恢复均以临时目录验证。
- 使用隔离的非空药品目录实际生成 10 个页面，在浏览器 1440×1000 与 390×844 两个尺寸核对查找、旧链接、详情、翻页、返回和官方来源地址。手机使用响应式模拟，示例外部来源只核对链接目标。投稿、审核、转入和整份目录发布均另外通过浏览器实际操作。
