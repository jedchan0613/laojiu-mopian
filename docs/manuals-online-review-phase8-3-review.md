# 说明书8.3：整册与官网线索接入未公开草稿

完成日期：2026年11月16日。依据[8.1设计](manuals-online-review-phase8-1-design.md)及[验收清单](manuals-online-review-phase8-acceptance.md)。本阶段仅本地开发与合成验收，未执行服务器操作、提交推送、部署或真实资料入站；8.4、8.5尚未执行。

## 已完成的行为

- 已通过专用审核的非PDF图片册，可由管理员人工选择RPR/OTH和接收日期，按审核的完整页序生成待入站副本、SUS/Y/U0未公开档案草稿和说明书目录草稿。保留页身份、原纸面页码和内容摘要，不自动改页码，不自行补正式元数据或公开。
- 官网线索只产生目录草稿，包含人工填写的来源名称、核对日期和可用状态；不分配档案编号、不复制图片、不抓取外链。完成后只显示目录维护入口；图片册另显示档案维护入口。
- 线上转入需独立审核/转入开关、既有目录维护及真实Linux条件全部满足；默认关闭。目录损坏、未初始化或不可用时，审核仍可读取和保存，转入停用。线上PDF能力始终为0，本机既有PDF流程保留。
- 同一本册只允许一套交接结果；原操作/步骤编号可读取成功回执，换内容、换身份或另起操作重复交接均拒绝。品牌和完整型号精确匹配，遇别名、品类或版本冲突停止，不猜测合并。

## 中断与来源保护

复制前先保存永久编号、稳定目录键、操作者、操作/步骤编号、提交摘要、目录版本及完整源页清单；每页写后保存检查点。编号分配同时排除未决预留及待入站目录，不能重用残留编号。写入前检查整册上限和磁盘余量，目录写入也做容量检查。

部分复制或草稿/目录写入后出错，保留已写内容和定位记录，进入needs_review；不自动删图、不谎称取消已全部撤回、不重复复制。新受保护的resolve-operation仅接受原operationId/stepId，以服务端身份核对已有记录，不重新执行业务。只有提交、审核、交接、档案草稿、全部副本字节及目录草稿一致才能补成功回执；无日志、缺页、版本冲突或证据不足继续冻结。确定未写入的已有失败/取消回执仍可按现有查询处理。

manualTransfer回执使用严格白名单，包含投稿、提交版/摘要、保存后记录版、目录键、可选档案号、页数与提供方式；不含身份、内部依据、文件数据。旧程序不能安全读取新回执时必须保持开关关闭和停写，8.4再核验升级/回退兼容性，不能直接降级后自动恢复写入。

非PDF也重新核验17项人工确认、依据、审核身份和完整整册映射。目录按稳定键反查私密来源，不能通过删除来源字段、先删后同键重建或扩大授权范围绕过检查。普通/批量档案、译文、撤销、目录、合并/撤销合并及Git发布共用来源检查；公开生成处还核验实际公开副本字节、路径和链接类型。

长构建不持整册投稿锁，投稿人的停止申请可正常落盘。真正切换公开版本前，按投稿编号顺序取得同一册锁、复读已核对快照并持锁执行实际rename。Git发布的检查在发布进程内重新准备，不能只信任早先同步结果。最终提交后守卫异常时保留实际新版本并提示核对，避免删除live所指版本。已公开后收到停止申请不会被伪称自动下架。
