# 说明书线上维护7.2：草稿、保存与受保护预览验收

完成日期：2026年11月13日。状态：7.2本地开发和合成检查完成，未部署服务器；7.3正式发布接入尚未执行。

配套文件：[7.1设计](manuals-online-maintenance-phase7-1-design.md)、[阶段验收清单](manuals-online-maintenance-phase7-acceptance.md)、[开发阶段计划](manuals-development-plan.md)。

## 一、交付内容

1. 工作台的电脑和手机“说明书维护”入口改为按服务器能力显示，修复导航样式覆盖隐藏属性的问题。未读取到明确能力时保持隐藏。
2. 已登录管理员直接访问未开放的维护页面，显示中文说明和返回管理入口；接口仍拒绝访问。编码、大小写和静态文件路径不能绕过关闭状态。
3. 线上模式可在独立开关下编辑品牌、型号、说明书、别名、多来源、页序和目录，保存私密草稿，重新进入后继续编辑；保存不改变正式目录和访客页面。
4. 增加首次保存的空目录确认及基线校验，记录服务端验证的管理员身份。已有公开资料却缺少完整私密记录时，只读说明并拒绝覆盖。
5. 状态损坏、目录冲突、中断事务和无法核对的公开输入阻止相关写入；有效的继承公开投影仍保留，不能被空状态替换。
6. 草稿预览绑定已保存版本，支持翻页、跳页、目录、放大和单页重试。图片从同域受保护接口读取，只取关联档案的正式公开副本，不回退到同名待入站图片。
7. 公开说明书库和原档案链接由服务器提供的公开域名生成。管理依据和备注统一显示“仅管理端”，本机模式保留原有发布流程。
8. 线上发布、撤下及历史恢复均保持不可用；投稿专用审核和PDF能力继续独立。收件箱按专用审核能力决定是否提供操作入口。

## 二、开关与能力

新增设置沿用7.1设计，默认关闭：

```text
LJM_MANUALS_ONLINE_ENABLED=false
```

本轮没有创建或修改服务器环境文件。隔离测试临时设为true验证草稿功能；正式服务器启用仍属于7.5的上线清单。

为区分7.2的草稿能力与7.3的完整维护，补充`manualsDraftMaintenanceVersion`，与既有`manualsMaintenanceVersion`分开。该字段不是另一种管理员身份或权限系统，所有访问仍先通过原Access登录保护。

| 模式 | 草稿能力 | 完整维护能力 | 专用审核／PDF交接能力 |
| --- | --- | --- | --- |
| 本机 | 1 | 1 | 沿用原本机能力1 |
| 线上开关关闭 | 0 | 0 | 0 |
| 线上开关开启、本轮7.2代码 | 1 | 0 | 0 |

同一能力对象用于健康接口、完整和split工作台响应、收件箱响应及维护页面上下文。工作台缓存摘要包含这些能力，开关切换并重启后，旧缓存不能维持失效菜单。

线上尝试调用发布前检查、正式发布、撤下或恢复接口，返回`MANUALS_PUBLICATION_UNAVAILABLE`；界面隐藏发布操作并禁用历史恢复。不能只把菜单显示出来就认为整套线上发布已经完成。

## 三、保存与首次使用

### 持久位置

资料继续保存在`${LJM_ADMIN_DATA_ROOT}/manuals/`，包括`state.json`、`history/`及既有事务目录。与程序版本、公开网站、账号数据库和原始主库分开。未新增数据库或依赖包。

草稿仍按整个目录保存。目录版本和原操作编号防止旧页面覆盖及重复执行；保存前保留旧草稿历史。初始化及草稿历史中的操作者取自服务端Access身份，忽略浏览器自报的身份。

### 首次确认

- 私密记录不存在且公开目录为空时，页面显示首次建立说明，确认框未勾选前不能保存。
- 首次保存必须同时提交当前目录版本、空公开输入摘要及明确确认。服务端重新核对，不能沿用过期的空目录判断。
- 若已有任何正式目录条目，即使关联档案后来失效导致公开投影为空，也不能直接建立空状态覆盖它。
- 如果私密正式目录与公开输入不一致，或者记录损坏、有中断事务，页面只读，保存和相关同步均停止，原文件保留。
- 保存前预留16 MiB余量，再加两倍待写状态及旧草稿历史所需空间；空间不足或无法核对时拒绝写入，不删除历史或图片。

切换到另一程序目录并重启的合成检查中，仍能读取同一草稿、历史及目录版本；未公开草稿没有进入新版本的公开输入。

## 四、预览边界

新增`GET /api/manuals/preview-image`，参数仅为manual、revision及page。服务端根据目录确定附件，核对关联档案的ACT/G/U3、类型与schema、附件归属、页序、路径及图片签名；不接受任意文件位置或外部下载网址。

预览页面、JSON和图片均沿用管理员身份及`no-store`保护，没有扩大CSP、CORS或公开站点路由。真实源PDF、待入站副本和回收副本不能经该入口读取。草稿版本改变后，旧预览和旧图片地址均失效。

预览页原来拼接`?retry=`的逻辑已适配带参数的图片接口，避免重试破坏版本和页序参数。浏览器检查发现长文字会撑宽手机页面，已补充换行和布局约束；390像素下翻页、跳转及放大不造成整页横向溢出。

### 测试方式和修正

线上HTTP夹具只在临时目录启动真实online模式服务，使用临时签名密钥和合成Access身份。仅测试子进程的证书获取指向合成公钥，正式签名、有效期、受众及邮箱核验全部执行；生产代码未引入测试登录或鉴权旁路。

首次夹具缺少线上必需目录，原启动检查按预期阻止启动，补齐了合成目录；错误内容类型的断言按现有415响应修正，没有放宽保护。界面阶段修复了手机长文字溢出；补充开关重启与旧ETag检查后重新运行完整回归，以上表格记录最后一次结果。

浏览器合成网关和临时线上模式进程已停止，浏览器尺寸覆盖已重置，测试标签页已关闭。没有发送真实邮件或调用真实官方来源抓取。
