# 药品说明书独立维护设计

2026 年 11 月 19 日 · 阶段 9.1 设计稿　[打开可操作的布局示意](manuals-medicines-layout.html)

## 从哪里进入

在管理工作台点「说明书维护」，标题下第一行并列显示 **物件说明书｜药品说明书**。即使一条药品都没有，两个入口也都可见。选「药品说明书」后，主按钮为「新增药品」。进入后可直接输入药名，无需预先建立品牌、型号或企业。物件区继续使用熟悉的品牌、型号、说明书三个页签。

## 如何排版

| 位置 | 桌面 | 手机 |
| --- | --- | --- |
| 顶部 | 工作台名称、两类入口，当前类别有文字和选中样式 | 两个入口并排可见 |
| 查找 | 左栏约占三分之一，顶部为药品搜索和「新增药品」。每条先写通用名，再写剂型、规格、企业。商品名、批准或注册编号也可搜索 | 先显示列表。点一条进入编辑，返回时保留之前的搜索和位置 |
| 编辑 | 右栏先放药品资料，随后是该药的说明书版本。常用字段两列排列，附加信息收起 | 单栏依次显示字段，进入版本详情才展开来源及页图。操作按钮避开软键盘 |
| 操作 | 编辑页的主操作是「保存草稿」。提交成功后可预览，再进入单独的目录发布检查 | 未保存就离开时可继续编辑或放弃修改。保存后回到刚编辑的记录 |

版本之间用列表行区分，不把几版原文同时展开。空药品列表显示「还没有药品」和「新增药品」。有药品、无版本时，在其资料下显示「添加第一份说明书」。搜索无结果时保留搜索词，并提供「清除搜索」。

## 药品表单

| 字段 | 摆放和填写方式 |
| --- | --- |
| 通用名 | 首行，列表标题。按原件填写。只有历史原名、通用名尚待核对时，可用「原件题名」暂存和检索 |
| 剂型、规格 | 两个独立的短字段，按原件照录。对历史资料保留原写法。包装数量另列，避免把每盒数量混为药品规格 |
| 企业 | 显示角色和名称，默认提供「生产企业」。可改为「上市许可持有人」或「原件署名，角色待核」，也可增加另一角色。按明确角色分别保存。名称直接输入，可选择已有写法 |
| 更多信息 | 商品名、原件题名或旧称、批准或注册编号、包装规格。编号可同时填写原件上的名称和原值，适应不同地区、年代 |

草稿有通用名或原件题名即可开始保存，其余可逐步补。正式收录前，检查能否依据原件辨别适用对象；缺失的字段显示「未载明」或「待核」，无法辨别时保留草稿。归档字段不包含适应症、用法用量等正文摘编，读者通过对应版本的说明书原文查阅。

## 说明书版本

点击药品下的「新增版本」，默认关联当前药品。在原件明确适用于多个规格时，可追加关联已有药品记录，一份原文只维护一次。

| 字段组 | 版式和规则 |
| --- | --- |
| 版本识别 | 一项「版本标识」按原件填写，如「某年版」或「版本未注明」。语言、地区沿用现有选项。可分别照录核准日期、修订日期，只有年份也允许保留原文。收录日期单独记录 |
| 来源与原文 | 提供「官方来源」和「已审核页图」，同一版本可兼有。前者填来源名称、链接和核对日期，后者选择已审核发布副本，排列页序、核对缺页。页面随所选来源展开相应字段 |
| 版本列表 | 显示版本标识、语言、可用原文和发布状态。点击一行查看详情。新增修订版建立另一条版本记录，既有版本可继续阅读 |
| 人工核对 | 核对药名、剂型、规格、企业角色与原文的对应关系，以及版本、来源、页序、权利和隐私。版本上的历史署名和编号作为该版依据保留。日期靠后本身不能说明版本当前有效 |

**示例流程**　手上有同一种药的两份不同时期说明书。先建一条药品，录入首份说明书并保存草稿。以后查到该药，点「新增版本」录入第二份。遇到同通用名、不同规格或不同生产企业，系统展示相近项及区别，由维护者选择已有记录或另建。旧企业名仅在有依据时作为历史写法关联，不凭名称相似合并。

## 与现有系统衔接

- 建议增加独立的药品记录，使用稳定编号。普通说明书继续关联物件型号；药品说明书通过药品编号关联一项或多项药品。共用同一套说明书版本编号、页图、来源、预览、历史和撤下操作。
- 现有目录整份保存。应先让读取、保存、发布检查、公开输出和历史恢复都识别新结构，再启用药品写入。旧页面提交不能抹去新增药品字段。药品与物件之间切换时，已编辑内容应得到保留或提示。
- 逐条识别旧的 `medicines` 型号记录，保留原文、原标识和说明书关联。原品牌的企业角色、原型号的药学含义须人工确认。有歧义的条目进入「待整理」。重复执行整理只更新同一记录。混合关联药品与物件的旧说明书须人工拆分或确认，旧详情链接仍可打开。
- 药品投稿及审核使用药品字段。已提交的历史快照按原样可读；转入时提示匹配候选，核对后才生成私密草稿。旧物件投稿继续按原流程办理。
- 访客查询仍支持原有药品筛选和说明书详情地址。药品结果用「通用名 · 剂型 · 规格」和企业辨别资料，展示版本数量、原文阅读及官方来源。管理端药品入口始终可见；公开查询只计已发布版本。
- 首版沿用整份目录发布。发布前分列「药品说明书」「物件说明书」本次新增、修改、撤下数量，可以展开看具体条目，再确认「发布整个说明书目录」。保存单条药品草稿后，访客看到的内容须经这一步才更新。
