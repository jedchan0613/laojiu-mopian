# 手机端档案维护第二阶段验收

完成日期：2026-10-18。范围：服务端写入保护及现有入口衔接；第三至第五阶段尚未执行。

## 本阶段的结果

两个页面读取同一件档案后，先保存的一方保留；后保存的旧页面收到冲突提示，不能覆盖新版本，页面输入继续保留。重复提交同一项操作可以查询原结果，不会再次分配编号或再次构建。

实现继续使用 Node 内置模块，没有安装新的依赖、数据库或公开服务。操作保护放在 `local-admin/write-coordinator.mjs`，档案原有 `core`、`metadata`、`public_view` 及永久编号规则不变；版本信息只放管理响应和私密草稿包装层。

## 已落实的保护

- **统一安排写入。** 保存、编号分配、发布、批量发布、撤销、三种恢复、投稿转草稿和五种语言的译文保存／发布进入同一队列。档案列表、版本查询和译文读取也等当前写入结束后再取快照。采用全局串行方式，结构简单，代价是构建期间其他写入要等待。
- **比较页面版本。** 读取时提供正式记录与草稿共同计算的版本摘要，提交时必须带回；实际写入前再次比较。新建必须带明确的 `new` 标记。批量发布逐件核对版本；译文和投稿保留原有修订号检查并接入共同队列。
- **避免重复执行。** 一次操作有父编号，上传每张图片、保存、发布分别有子编号。相同父／子编号及相同请求只执行一次；改变目标或内容会被拒绝。成功重放只返回精简收据，不冒充当前档案版本。图片重放也核对实际字节。
- **确认真实终态。** 私密收据在操作开始前落盘，记录排队、执行、成功、失败、已取消或待核对。重启后尚未结束的操作转为待核对，暂停后续写入；不会自动重新建档或发布。成功收据可在重启后继续查询。
- **安全处理取消。** 取消请求等待该项写入、恢复及收据结束；已经成功的结果不会被说成取消成功。网站构建不直接中止底层 npm／shell，而是等完整构建结束后检查取消并恢复，避免 Windows 下子进程仍写文件、队列却提前放行。
- **保护草稿与历史。** 只有当前发布的草稿版本仍一致时才清理；发现另一版本则保留。批量改为每件构建成功后再清理该件草稿，失败件保留并恢复其正式版本，因此比原先最后统一构建慢。原有人工隐私检查、历史和回收规则继续执行。
- **衔接旧入口。** 手机和电脑请求统一带版本及父／子编号；旧页面或旧工具缺字段返回 428 并要求刷新／更新。新页面也会拒绝没有写入保护的旧服务。批量工具在私密批次的 `_operations/` 下保存固定编号和请求摘要，网络重试复用；重启先查成功收据，可找回未写入结果表的成功记录。

## 私密操作目录与维护边界

默认目录为 `local-admin/operations/`；配置私有数据根目录时位于其 `operations/` 子目录，隔离样例则位于测试副本的 `private/operations/`。该目录已加入 Git 忽略规则，不能设在网站或管理静态文件目录中，公开构建检查也禁止混入 `operations` 或操作查询程序。

收据只允许保存父／子编号、目标编号、请求摘要、时间、状态、错误代码及精简结果（档案编号、版本摘要、批量成功标记、临时图片编号／摘要／大小、译文修订号）。不保存档案标题、正文、图片内容、完整文件路径、联系方式、Cookie、登录令牌或密钥。POSIX 环境目录使用 0700、文件使用 0600；Windows 继续使用所在私密目录的访问权限。

默认最多保留 10,000 条收据或 32 MiB；每个未完成操作预留 32 KiB 终态空间。达到上限会停止接收新写入，不会自动删除历史。失败、已取消和待核对操作不会自动换号重做。批次修正前应先核对原结果，再建立修正批次；不能通过删除 `_operations/` 或服务器收据来“重试”。

遇到“待核对”时，可继续查看资料，应保留页面和操作编号，由维护人员对照正式档案、草稿、图片、历史和构建记录判断结果，再安排恢复写入。本阶段不提供自动消除未知结果或自动解决内容冲突的按钮。

同一私有数据目录只允许一个新版管理进程或同步命令占用。正常停止会等待已受理操作结束后再释放；已确认死亡的进程占用可以回收，无法核实的占用记录保持停止。升级时必须先安全停止旧版管理进程，不能混跑新旧服务。

命令行 `--sync-site-data` 也遵守占用与待核对检查。直接修改 JSON、直接执行站点构建及既有自动部署不会凭空获得这个队列的保护：后续上线前，必须先停止管理写入、确认无处理中操作，再运行维护／部署步骤。当前阶段没有修改部署定时器或生产服务配置。

## 本机样例与停止点

样例：<http://127.0.0.1:4194/admin/>。只使用合成资料，只在这台电脑访问。启动方式：

```powershell
node local-admin/mobile-preview.mjs --stage=2
```

停止该样例服务后，可运行：

```powershell
node local-admin/mobile-preview.mjs --stage=2 --build
node local-admin/mobile-preview.mjs --stage=2 --verify-protected
```

本阶段未改动真实档案、未操作项目外原始主库、未推送、未部署或连接生产服务器。账号业务数据继续独立保存，既有认证与隐私门槛没有降低。

第二阶段到此完成。保存中继续输入、自动保存节奏、中文输入法、断网／登录恢复及逐张上传恢复属于第三阶段；隐私确认绑定图文版本与完整发布专项属于第四阶段；线上和安卓真机属于第五阶段。
