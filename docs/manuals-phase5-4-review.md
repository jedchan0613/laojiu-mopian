# 说明书专用投稿5.4验收与操作说明

日期：2026年11月11日  
范围：说明书专用人工审核、具体提交版本绑定、转入未公开档案与目录草稿，以及长册全过程验收。  
状态：本地开发与验收完成。没有真实资料入站、代码提交、推送、部署或服务器操作。

## 从哪里进入

1. 如果旧管理服务还在运行，先保存其他页面的工作，关闭原启动窗口，再双击项目根目录的 `启动档案管理.cmd`。本次没有启停日常4173服务。
2. 打开工作台的“投稿审核”，或访问 `http://127.0.0.1:4173/admin/submissions.html`。
3. 在“处理状态”选择“说明书投稿”，选择一份来稿，再点击“打开说明书专用审核”。专用审核页仍位于既有本机工作台，不是新的云端后台。
4. 页面显示当前记录版、最新提交保存版、处理状态和已提交版本。可以查看旧版、逐页翻阅或跳页；只有最新提交且状态允许时，才能记录审核或生成整理草稿。

开发和自检由Codex完成。这里的人工核对是维护者日后使用网站时作出的资料判断，包括真实来源、型号、权利和隐私；程序不替维护者猜测普通人的身份或作出公开授权。

## 怎样审核

- 需要补充或暂不采用：选择处理结果，在“给投稿人的说明”写清原因，再保存。投稿人能看到说明及状态，按原编号补充后重新提交；内部备注只在私密工作台保存。进度通知沿用既有账号设置，本次用私密文件邮件通道验收，没有向真实邮箱发信。
- 通过审核：先逐页核对本册，再填写型号适用、来源、权利与提供范围三项依据，并逐项完成4项说明书检查及13项隐私检查。没有全选捷径，也不能用空白依据代替核实。
- 本次处理绑定具体提交保存版、完整信息摘要和逐页图片摘要。投稿人补充、撤回或重新提交后，旧审核表不能继续处理新版；审核填写仍保留，重新读取前会提示。
- 查看历史版本会明确显示保存版号，旧版只能阅读。重新读取后，确认框清空，不能把上一次的勾选自动用于新版本。

“通过人工审核，待整理”不代表已经公开。后续整理可能改变公开文字或图片，正式发布仍检查整理后的草稿。

## 怎样接到整理流程

审核通过后，页面下方可使用“接到未公开整理草稿”。填写整理后的题名、物件名称、地区、版本及可公开简介，再确认本次影响。投稿人的补充说明和本页私密说明不自动复制进公开档案字段。

### 提供站内阅读副本

1. 人工选择既有“复制件”或“其他”类型，填写实际接收或获得日期；不以今天或手册印刷日期代填。
2. 点击“生成未公开整理草稿”。系统按本次提交的完整页序逐张核对并写入待入站区，生成一份未公开档案草稿及一份说明书目录草稿；保留页面身份、纸面页码和私密来源记录。
3. 新档案使用原有 `core`、`metadata`、`public_view` 结构，类型只用既有RPR／OTH及common结构。初始为SUS／Y／U0，权利状态仍为UNK，不因投稿人的声明自动取得公开或下载权限。
4. 使用“打开未公开档案或已有档案”继续补全必要信息、核对图片和隐私，按既有正式发布流程检查与构建。
5. 使用“打开说明书目录草稿”。当前引用和全册页序已经保留；如果档案尚未公开，会明确显示编号与“尚未通过公开检查”，目录发布被阻止，不会因为资料已通过投稿审核而绕过档案门禁。
6. 档案按原流程完成本地正式发布后，回到说明书维护重新读取，预览已保存资料，执行“发布前检查”，再逐项确认生成本地正式目录。

200页长册沿用单册200页及既有容量限制，逐张转入，不通过一次巨大的图片表单传输。长册在两个基础图片名后可使用到 `detail-198-public.jpg`；普通投稿的八图限制和其他上传上限保持原样。公开构建的图片压缩同时识别这些长册副本名。

### 仅提供官方来源线索

填写来源名称、实际核对日期以及核对时是否可用，再确认生成草稿。系统只生成品牌、型号和官方来源目录草稿，不复制图片、不创建实物档案、不分配永久编号。

程序只检查网址格式，维护者必须实际判断是否属于厂家及是否适用于该型号。来源地址、名称、日期、可用状态及依据会进入目录维护，私密依据不会进入公开投影。通过预览和发布前检查后，仍须逐项确认才能生成本地正式目录。

## 保留和保护

- 沿用既有账号、私密投稿区、本地写入队列、操作回执、待入站区、档案草稿和说明书维护，不新增依赖、数据库、服务或CMS。
- 目录按明确品牌名和完整型号复用已有条目，不覆盖原有品牌、型号或其他草稿。遇到别名冲突、重复版本或已有资料不一致时，会先报出问题，不猜测合并两个型号或两份投稿；应核对目录或要求投稿人补充纠正。
- 目录草稿带有私密的投稿及版本来源绑定。普通保存不能手工添加或删除该绑定；公开投影按既有白名单生成，不含账号、投稿编号、内部依据和审核备注。公开目录编号使用独立摘要，不保留可直接还原的私密投稿编号或其尾段，同一交接仍能稳定去重。
- 仅允许官网线索的绑定不能在维护页被扩大成站内阅读副本。原始文件、未审核图片及本页私密说明不进入公开目录。
- 转入前先核对目录版本和冲突；响应丢失时查询同一操作回执，不重复创建档案或目录。交接中断而无法证明全部完成时，保留未公开结果和编号，暂停后续写入，要求核对，不自动猜测成功或重放。
- 进入整理后，投稿人仍可“申请停止处理”。申请会保留，阻止后续档案和目录发布；实际撤下或资料处理继续使用既有目录、档案管理流程，不自动删除图片或档案。目录构建期间收到申请也会回退本次发布。
- 专用审核页和接口仅在本机模式开放，线上模式返回不可用。普通审核和普通转档案入口仍不能代替说明书专用确认。
