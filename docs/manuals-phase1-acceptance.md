# 说明书专栏第一阶段验收清单

日期：2026年11月10日  
配套：[详细设计](manuals-phase1-design.md) · [演示资料与查询场景](manuals-phase1-samples.md)

本清单区分“本阶段设计检查”和“后续功能验收”。页面示意可点击，不代表正式网站已具备这些功能。

## 一 本阶段设计检查

| 检查项 | 通过条件 |
| --- | --- |
| 品牌、型号、文档关系 | 一型号多版本、多型号共用一文档均有明确规则 |
| 正式档案关系 | 保留永久编号和core、metadata、public_view；不新造对象类型 |
| 字段要求 | 必填、未知、数组和私密字段清楚，馆藏公开文字不双重维护 |
| 页面结构 | 查询、详情、阅读、型号帮助和手机布局能够查看 |
| 来源差异 | 官方索引与站内阅读使用不同提示和操作 |
| 异常情况 | 无结果、缺页、来源失效、加载失败和撤下均有处理说明 |
| 演示隔离 | 全部虚构，不含真实编号、主档、私人信息或可操作的设备指引 |
| 部署衔接 | 明确持久数据、投影生成、私密排除和继承问题 |
| 后续工作范围 | 预计文件与阶段清楚，不提前开发投稿或PDF |

本机原型位于 `outputs/manuals-phase1/prototype.html`，样例数据位于同目录；均受现有 `outputs/` 忽略规则保护，不接入生产代码。

## 二 后续功能验收

第二阶段完成查询、阅读与导航后，应逐项执行样例文档中的Q01—Q24场景，并记录实际结果。第三阶段补齐发布、历史、撤下与隔离检查；第四阶段执行真实资料与生产验收。

### 查询与阅读

- 准确型号、品牌别名与允许的格式差异可正确识别；型号后缀、字母数字和跨品牌同名不会混淆。
- 查询结果按型号分组，文档与型号计数正确；语言、用途与获取方式筛选互相一致。
- 官方索引清楚跳转到核定来源；站内阅读显示实际页数、纸面页码和缺页。
- 翻页、目录、放大、返回和分享状态在手机与电脑上可用。
- 无结果和加载失败有不同提示，不把错误数据当作正常空结果。

### 发布与隐私

- 未经批准的目录、草稿、撤下资料和关联未公开档案不输出到详情、索引或图片入口。
- 目录不能覆盖档案公开条件或下载策略，修改后重新核对。
- 私密目录进入仓库忽略、部署排除、公开产物门禁和服务访问隔离检查。
- 真实图片只来自批准的inbox副本，不读取或改写外部主档。
- 正式构建失败不替换上一份可用结果；历史恢复只生成草稿。
- 更新上线只影响指定资料与功能，保留既有档案、账户和投稿数据。

## 三 交付说明

本阶段检查结果在开发日志中记录。正式查询算法、档案发布门禁、真实附件加载和生产部署尚待后续阶段实现与检查，不能用原型演示代替它们的验收。

## 四 本阶段实际检查结果

2026年11月10日已完成以下设计检查：

- 16项样例与原型静态检查通过，覆盖标识、引用、去重统计、语言、缺页、演示隔离、脚本语法和无外部提交入口。
- 原型中的准确型号、官方索引、缺页、无结果、来源失效、撤下、加载失败七种预设场景及重试操作核对通过。
- 原型打开阅读、翻页、目录跳转与纸面页码分别显示核对通过；连续查看同型号其他文档后返回仍保留原查询条件。
- 在320、390、1280像素宽度下分别检查列表、详情、阅读、无结果、来源失效，共15组页面未出现整页横向溢出。
- 已视觉检查桌面查询、桌面阅读、手机详情和手机阅读，截图保存在本机 `outputs/manuals-phase1/`；浏览器未记录到原型脚本警告或错误。

上述结果仅说明第一阶段虚构原型与设计材料可审阅。Q01—Q24在第二阶段的执行结果另见[本地查询与阅读验收记录](manuals-phase2-review.md)，不能用第一阶段原型代替正式功能验收。
