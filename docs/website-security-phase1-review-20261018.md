后续决定：用户要求五点全部执行完再统一上线，第一批补丁暂存，不再单独上线。以下验收及当时的上线申请为阶段记录，当前执行顺序以更新后的总方案为准。

本批只处理优化方案第 1、2 项：图片处理安全、HTML 脚本中的文字数据安全输出。用户同意按计划开始执行；计划明确每批独立验收、线上操作另行授权，因此未推送 main、部署程序、切换公开版本、重启正式服务或修改服务器配置。缓存、性能和外语复核仍未实施。

## 一、实际修改

### 图片处理

- 新增零依赖共用工具 `shared/publication-image-safety.mjs`。先读取真实签名字节，核对 JPEG/PNG/WebP 扩展名与已声明的 MIME（上传类型），再进入图片库。类型缺失或通用二进制类型不作为格式证明，仍必须满足真实字节与扩展名一致。
- 免注册投稿、账号新稿、草稿添加/替换图片共用前置检查；multipart 表单不再丢失文件的类型声明。匿名新稿的非法格式在加载原生图片库、创建投稿目录之前被拒绝。
- 管理员上传及暂存恢复复用同一个签名识别，不取消原有主档文件名、大小、上传凭据、人工隐私确认和发布门禁。管理员上传仍接收发布副本，不新增自动重编码原副本的步骤。
- 图片库明确禁用 HEIF/AVIF、SVG、TIFF、PDF、GIF 解码器父类，覆盖它们的缓冲区/文件入口；保留 JPEG/PNG/WebP。字节筛选不是完整性证明，后续继续执行安全解码、元数据清理、动画/多页拒绝和像素限制。
- 网站响应式构建先检查文件头，再使用同一安全入口读取需要生成的图片。既有变体仍按摘要复用，不强制批量重编码；生成格式、尺寸、质量和原有构建器像素上限不变。投稿仍为每图 5 MB、合计 20 MB、最多 8 张、4000 万像素、输出最长边 2400 的原限制。

### 文字输出

- 新增 `shared/html-json.mjs`，只用于 HTML 脚本数据块，转义 `<`、`>`、`&` 及两个 Unicode 分隔字符；JSON 解析后逐字还原，不清洗或删除题名、说明、原文、译文。
- 详情浏览足迹数据、目录检索数据、结构化数据、首页和 404 随机编号索引统一使用该函数。普通文字与 HTML 属性保留 Astro 默认转义，轮播属性及图库属性不混用脚本转义。
- 合成资料揭示现有公开检查器把图片属性内的 `>` 当成标签结尾，会误报缺少尺寸；仅修正其图片标签识别表达式，仍检查实际 width/height，未放宽检查条件。
- 未修改首页逐类首图、手动切换、上下去重、相册入口、分类及逐件计数规则。

## 五、待授权的本批上线范围

只申请以下一批程序上线，不包含第二至第四批：

1. 提交并推送本批补丁至 main，触发既有自动部署；服务器按锁文件安装已验收的现有依赖树。上线会按既有流程排空管理写入并切换管理、投稿、账号和点赞程序，服务可能短暂重新连接，公开浏览由旧公开版本持续提供。
2. 上线前核对当前应用/公开版本及资料基线。只使用服务器自身最新档案、图片、译文和账号数据，绝不把本机生成资料或合成测试目录上传覆盖生产。
3. 保留既有人工隐私、字段、schema、历史、回收、构建和安全切换门禁。服务器正式构建成功后才切换；不改 Caddy、邮件、域名、账号开关或其他功能。
4. 上线后核验实际库版本、六语言首页/目录/详情/图片、管理与账户私密响应、既有服务状态及资料一致性；不代替用户发布或撤销真实档案。
5. 上线失败优先保留旧公开版本，按现有流程恢复对应程序，不回退或覆盖后来新增的业务数据。若必须退回有已知风险的旧图片库，明确标为未安全完成；是否暂停新上传须再取得授权，不能自行关闭注册/上传。
