日期：2026年11月10日  
性质：全部为虚构设计样例，不代表已收录资料，不用于真实设备操作。

## 一 样例范围

演示使用“示例甲牌”和“示例乙牌”。型号以 `EX-` 开头，标识以 `demo-` 开头；不使用真实人物、手机号、地址、真实商标图像或任何 `LJM` 档案编号。官方链接示意仅使用不可访问的 `example.invalid` 域名，在原型内不会打开外站。

| 型号标识 | 品牌与型号 | 物件名称 | 演示目的 |
| --- | --- | --- | --- |
| `demo-model-001` | 示例甲牌 EX-RC100 | 电饭煲 | 一个型号有不同版本和用途 |
| `demo-model-002` | 示例甲牌 EX-RC100A | 电饭煲 | 后缀不能被忽略 |
| `demo-model-003` | 示例甲牌 EX-RC200 | 电饭煲 | 经明确依据共用一份手册 |
| `demo-model-004` | 示例乙牌 EX-RC100 | 小型加热器 | 不同品牌的同名型号分开 |
| `demo-model-005` | 示例乙牌 EX-CM20 | 胶片相机 | 旧物件、缺页与纸面页码 |
| `demo-model-006` | 示例乙牌 EX-TC10 | 录音机 | 来源失效且无替代阅读方式 |

## 二 文档样例

| 文档标识 | 明确适用型号 | 版本与用途 | 展示状态 |
| --- | --- | --- | --- |
| `demo-manual-001` | 甲牌 EX-RC100 | 中文使用说明，2020年第一版 | 站内阅读示意，完整，6 张 |
| `demo-manual-002` | 甲牌 EX-RC100、EX-RC200 | 中英双语使用说明，2024年修订版 | 官方索引示意，可用；不创建两本 |
| `demo-manual-003` | 甲牌 EX-RC100 | 英文安装指南，版本未注明 | 官方索引示意，可用 |
| `demo-manual-004` | 甲牌 EX-RC100A | 中文使用说明，2022年版 | 站内阅读示意，完整，6 张 |
| `demo-manual-005` | 乙牌 EX-RC100 | 中文使用说明，版本未注明 | 官方索引示意，可用 |
| `demo-manual-006` | 乙牌 EX-CM20 | 日文使用说明，约1980年代 | 站内阅读示意，现有4张，缺页 |
| `demo-manual-007` | 乙牌 EX-TC10 | 中文使用说明，版本未注明 | 官方来源失效、无站内副本，不计可用 |
| `demo-manual-008` | 甲牌 EX-RC200 | 中文快速入门，版本未注明 | 草稿，只在异常场景中说明，不进公开结果 |
| `demo-manual-009` | 乙牌 EX-CM20 | 中文使用说明，版本未注明 | 已撤下，不进公开结果，不输出全文 |

官方索引“可用”是模拟状态，不表示示意地址可访问。阅读页均为自制版面示意，不含实际设备步骤、参数或维修说明；“站内阅读”是设计情形，不关联真实档案。

### 计数预期

正常可用列表应有 **5 个型号、6 份独立文档版本**：文档001至006，其中002关联两个型号但只计一份。来源失效的007另行提示；草稿008与撤下009不出现在公开查询。

若限定甲牌 EX-RC100，应看到001、002、003三份文档；不把 EX-RC100A 的004列为适用。选择中文后，003不再显示，002仍符合中英双语条件。

### 页序示例

文档001的六张示意依次为“封面、目录、部件名称、日常使用版面、保养版面、封底”；只模拟布局，不提供操作说明。其阅读页序3显示为“第3 / 6张 · 印刷页1”。

文档006有四张示意：“封面、印刷页1、印刷页3、封底”，缺少印刷页2。即使阅读页序连续，也必须显示缺页，不能将其标为完整四页手册。

## 三 目录格式示意

以下 JSON 展示查询信息的关联方式，仅为设计示例，不是正式档案数据或可直接发布的记录。展示图像来自原型自身，`linked_archive_id` 保持为空。

```json
{
  "schema_version": 1,
  "demo_only": true,
  "brands": [
    { "brand_key": "demo-brand-001", "name": "示例甲牌", "aliases": ["DEMO-A"] }
  ],
  "models": [
    {
      "model_key": "demo-model-001",
      "brand_key": "demo-brand-001",
      "model_text": "EX-RC100",
      "model_aliases": ["EX RC100"],
      "product_name": "电饭煲",
      "category_key": "home-appliances",
      "product_era_display": "2020年代"
    }
  ],
  "documents": [
    {
      "manual_key": "demo-manual-001",
      "model_keys": ["demo-model-001"],
      "document_kind": "user-guide",
      "languages": ["zh-CN"],
      "region_display": "示例地区",
      "edition_display": "2020年第一版",
      "edition_date": null,
      "completeness": "complete",
      "missing_note": "",
      "linked_archive_id": null,
      "official_sources": [],
      "page_map": [],
      "contents": [],
      "keywords": [],
      "demo_presentation": { "reader": true, "page_count": 6 }
    }
  ]
}
```

`demo_only` 与 `demo_presentation` 只能用于本阶段示意，生产读取器应拒绝；它们不能让空的档案引用通过正式站内阅读校验。功能枚举和 `category_key` 不属于 Excel 分类代码。

## 四 供第二阶段执行的查询场景

下列是验收输入与预期，不代表真实查询功能已经通过测试。

| 编号 | 输入或条件 | 预期 |
| --- | --- | --- |
| Q01 | 示例甲牌 EX-RC100 | 甲牌准确型号在首位，包含001、002、003 |
| Q02 | DEMO-A EX-RC100 | 已核定品牌别名等价，结果与Q01一致 |
| Q03 | 示例甲牌 ex-rc100 | 大小写不影响Q01结果 |
| Q04 | 示例甲牌 ＥＸ－ＲＣ１００ | 全半角转换后与Q01一致 |
| Q05 | 示例甲牌 EX RC100 | 已核定型号别名与Q01一致 |
| Q06 | 示例甲牌 EX-RC100A | 只将带A后缀的型号标准确，显示004 |
| Q07 | EX-RC100 | 甲牌与乙牌的同名型号分开，提示核对品牌 |
| Q08 | RC100 | 按型号片段给出相关结果，不标所有条目为准确型号 |
| Q09 | 示例甲牌 EX-RC200 | 显示共用文档002，草稿008不出现 |
| Q10 | 型号001＋语言中文 | 保留001、002，排除003 |
| Q11 | 型号001＋语言英文 | 保留002、003，排除001 |
| Q12 | 型号001＋安装指南 | 只显示003 |
| Q13 | EX-RC1000 | 不把EX-RC100或EX-RC100A当成准确型号 |
| Q14 | EX-RC10O | 不自动将字母O改为数字0 |
| Q15 | 品类“影音与摄影”＋有缺页 | 显示006，明确缺少印刷页2 |
| Q16 | 示例乙牌 EX-TC10 | 提示来源暂不可用，不假装有可阅读全文 |
| Q17 | 直接访问文档009 | 只显示不可用提示，不返回已撤下正文或图片 |
| Q18 | 输入含首尾及连续空格 | 不影响有效品牌与型号识别 |
| Q19 | 点击001，再返回结果 | 保留查询词、筛选和结果位置 |
| Q20 | 目录索引加载失败 | 显示加载错误与重试，不报告无结果 |
| Q21 | 正常列表统计 | 5个可用型号、6份独立文档；共用文档不重复计数 |
| Q22 | 两个型号的无分隔写法发生歧义 | 提示核对，不擅自合并或都标准确 |
| Q23 | 清空全部筛选 | 返回正常可用列表，草稿与撤下记录仍不出现 |
| Q24 | 阅读001的第3张 | 页序与纸面页码分别显示，目录跳转正确 |

原型只展示预设场景，用于看布局和交互顺序；上述完整查询逻辑、错误处理和真实数据保护须在后续开发中实现并验收。
