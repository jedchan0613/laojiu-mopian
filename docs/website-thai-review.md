# 泰语版本与语言选择验收记录

本阶段延续既有英语方案，新增泰语，不改变中文作为默认语言的规则，不增加依赖、翻译服务或新的账户数据系统。

## 页面与档案

- 中文沿用原地址，英语使用 `/en/`，泰语使用 `/th/`。首页、档案列表、详情、相册、关于、投稿、纠错、登录和账户页面共用既有功能。
- 三种语言共用永久编号、图片、分类代码及公开条件。泰语译文独立保存，不改写档案 `core`、`metadata` 和中文原文。
- 本轮为当前164件公开档案提供泰语：1217个文本字段、299条图片说明。原文转录仍按原语言展示，译文或摘要必须另外维护，不把原文冒充为泰语。
- 年代未知、推测地点、人物身份未确认和相册缺项说明保留；泰语页面日期使用公历，避免年份无意增加543年。
- 列表检索同时包含中、英、泰有效译文；分类筛选仍使用同一套内部值。

## 语言选择

顶部使用地球图标、当前语言和下拉箭头，展开后显示“简体中文 / English / ไทย”，当前项标记勾号。切换保留当前页面、查询条件和页面位置标记；支持键盘操作、Escape关闭、点击外部关闭。

泰语使用系统字体，单独调整行高、断行和首页标题，沿用网站纸张与墨色样式。没有新增网络字体请求。

## 维护与保护

- 原有外语维护区增加独立语言选择。英语文件继续在 `local-admin/translations/`，泰语在其 `th/` 子目录；线上对应私密数据目录。
- 两种语言各自保存草稿、正式版本和历史。切换语言前处理未保存内容，保存和发布带明确语言参数；未知语言拒绝处理。
- 译文逐字段核对来源。中文内容修改后，相应旧译文失效并回退到原文提示；未就绪的详情不进入对应语言的搜索引擎收录清单。
- 沿用审核确认、隐私检查、发布锁、失败恢复和管理访问保护。没有新增入站资料，没有访问或修改项目外主档。
- 账户固定提示和既有邮件模板支持泰语。访客昵称、投稿题名、留言和人工回复保持原文；测试没有发送真实邮件。
