# 安卓手机试用清单

入口：[现有受保护管理页](https://admin.laojiumopian.com/admin/)。请重新打开或刷新管理页以载入新版；只用你已批准的测试档案与发布副本。正式藏品仍须人工判断隐私，测试不代替授权。

先记录：手机型号、安卓版本、浏览器名称/版本、日期、Wi-Fi或移动网络。

1. **登录与只读**：未登录时应进入原有验证；普通网站注册账号不能变成管理员。登录后搜索一件，打开再返回，检查搜索、页码、位置和照片。
2. **中文与保存**：在测试草稿输入中文，组词途中不应打断。停止约5秒后应显示已保存；保存时继续输入，后输入文字应保留。重开已确认保存的草稿，永久编号与内容一致。
3. **相册与键盘**：从相册选两张经过筛选的小图，加不同说明、交换顺序、设首图。选图后不会自动上传，点保存才上传；重开后说明仍跟着图片。键盘弹出、横竖屏和大图关闭入口均可用。
4. **锁屏与断网**：只在测试草稿试。输入后切后台/短暂锁屏再回来；断网后不应显示成功。恢复后先核对，不应自动发布。强制关闭网页会失去尚未获服务器确认的输入，请勿用重要内容测试。
5. **离开与冲突**：有新修改时返回/切记录，应出现保存、继续编辑、放弃三选；先试继续编辑。电脑和手机同时打开同一测试件，先保存电脑，再保存旧手机页，应停止覆盖且保留手机输入。
6. **发布与结果**：先看预览和修改对照，再生成检查清单。13项应默认未选；缺一项不能发布；改图文后须重新确认。仅对你明确决定公开的测试件逐项确认并发布，完成后打开公开页核对文字、图片顺序及说明。

反馈格式：`第几项 / 通过或异常 / 手机与浏览器 / 出现什么现象`。有异常可附页面提示；请遮住私人资料。看到结果未知或冲突时，先保留该页面，不重复新建、不覆盖恢复。

目前状态：待用户真机反馈。开发环境与服务器自动检查不代表安卓真机已通过。
