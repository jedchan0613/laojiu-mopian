# 说明书PDF6.5：整理发布衔接与全过程验收

日期：2026年11月12日。用户指令：执行6.5。

状态：本地开发、自动检查及浏览器验收完成。PDF已接入原有5.4整理流程，经过审核的整册JPEG可生成未公开档案与目录草稿，再分别进行正式发布检查。使用合成资料走通200页上传、生成、审核、交接、隔离发布、撤下、恢复和私密备份恢复。

本次没有真实资料入站、Git提交／推送、代码合并、服务器操作或线上部署；6.6尚未开始。日常4173服务没有启停，全部实际发布、撤下与恢复都发生在新建的隔离测试目录。

## 从哪里进入、怎样使用

1. 先保存其他页面的工作，关闭旧的本地启动窗口，再双击项目根目录的`启动档案管理.cmd`。日常入口仍是`http://127.0.0.1:4173/admin/`，独立4236样例预览不承担账号和正式发布功能。
2. 进入“投稿审核”，筛选说明书投稿，选择来稿，点击“打开说明书专用审核”。按6.4检查当前提交版本，填写型号、来源和权利三个依据，逐项完成4项说明书、4项PDF及13项隐私检查，共21项。
3. 审核通过后，页面下方“接到未公开整理草稿”开放。人工填写整理后的题名、公开简介、物件名称、地区和版本，选择既有RPR复制件或OTH其他类型，并填写实际接收或获得日期。程序不代填今天，也不从PDF印刷日期推断接收日期。
4. 勾选本次交接影响，点击“生成未公开整理草稿”。仅复制该次审核的全部JPEG，逐张核对摘要及源PDF页序，写入既有待入站区；生成SUS／Y／U0、权利状态UNK的档案草稿和目录草稿。审核成功或生成草稿都不会自动公开。
5. 点击“打开未公开档案或已有档案”，补全正式必填信息，核对具体公开文字、图片和权利范围，完成原有13项隐私确认、发布清单及正式构建检查。真实人物、私人号码、地址、签名等仍执行原有硬停止规则。
6. 点击“打开说明书目录草稿”，重新读取目录。关联档案尚未公开时，会明确阻止目录发布。档案完成正式检查后，预览已保存资料，执行“发布前检查”，逐项完成目录的5项确认，再生成本地正式目录。
7. 访客通过说明书库查询品牌或型号，打开详情和逐页阅读。公开的是经过审核的JPEG及白名单资料；原PDF、原私密文件名、报告、源摘要、任务和账号信息不会随交接进入公开目录。

PDF整册的关联档案、图片、页序及纸面页码固定为本次审核结果。目录维护页将这些内容显示为只读，可补充阅读目录、整理公开文字；不能在这里混加、删除、重排或替换PDF页面。如需修正整册，应暂停发布，核对修正后的整份PDF并重新审核。此前未交接的PDF仍按6.4在原编号补充；已交接记录保持追溯，不提供自动解除绑定或覆盖旧提交的捷径。

图片投稿继续使用原来的页序整理能力；仅提供官方来源线索时，仍只生成目录，不抓取PDF、不生成实物编号，也不自动扩大阅读或下载范围。原PDF没有新增下载入口；普通图片的下载范围继续由原档案许可决定。

## 版本、来源和停止申请

| 情况 | 处理 |
| --- | --- |
| 未通过21项检查或缺少三个依据 | 不允许PDF交接 |
| 源PDF、处理配置、报告、生成页图或提交快照变化 | 交接和发布前重新核对，旧审核不能继续使用 |
| 目录或档案草稿换页、改序、改纸面页码，或来源摘要不一致 | 阻止发布；保留草稿，不猜测新的对应关系 |
| 已生成整理草稿后重复操作或丢响应 | 优先查询原回执；成功时找回原结果，不重复分配编号或创建草稿 |
| 交接中断，无法确认已完成 | 保留未公开资料及交接标记，暂停自动重复处理，要求核对 |
| 逐页校验或构建期间投稿人申请停止 | PDF发布不再长期占住同册的投稿锁；停止申请可立即保存，逐页深检结束及构建完成后重新读取状态，拒绝采用本次结果 |
| 单件或批量PDF档案发布失败、取消或复查未通过 | 恢复发布前的正式记录、源数据和页面，原草稿及私密历史保留 |
| 目录构建失败、图片改变、出现私密信息或期间收到停止申请 | 沿用原目录事务恢复目录和页面，保留草稿与失败结果 |
| 中断任务随备份恢复 | 已完成回执可查询；未完成任务标记中断或待核对，不自动重新转换或再次发布 |

私密交接记录保留提交保存版、快照摘要、PDF来源及配置的整体摘要、公开候选图片映射。档案草稿另外保留源页序、纸面页码、本页私密说明及逐页摘要；目录私密来源字段不能通过普通保存手工增加、删除或改写。正式档案只写入`core`、`metadata`和`public_view`，目录通过明确白名单生成公开输入，不复制这些追溯字段。

正式发布前及构建完成后，继续核对21项审核绑定、提交快照、源文件、完整生成记录、全部JPEG和实际公开候选。深检结束后再次读取投稿，检测校验期间的状态变化，不能继续采用开始检查时的旧状态。公开扫描既检查私密目录、文件名及序列化字段，也检查已知私密编号、账号、摘要、配置值和改名后的源PDF字节；不一概禁止网站中另有明确授权的其他PDF。

## 撤下与恢复

需要撤下整份说明书时，先在“说明书维护”选择该条目，点击“撤下正式版本”，说明原因并核对影响。成功后，说明书查询和阅读入口从下一份构建中移除；保留原档案、图片和历史。

如果还要撤下原档案，再到档案管理完成对应撤销流程。不要只删除某张图片或直接改公开JSON，这样会破坏引用和追溯。真实资料的撤下、停止申请和公开范围仍由维护者逐次判断，本次仅用合成资料测试。

在“历史与恢复”点击相应“恢复为草稿”，只恢复私密草稿；已存在的草稿先备份。档案撤销后的恢复同样产生SUS／Y／U0草稿，正式撤销记录不会因此自动公开。重新公开仍须完成档案与目录的检查和确认，恢复过程保留PDF来源绑定。

## 私密备份和页面回退

PDF档案发布会在现有私密历史区的`history/pdf-builds/`保留上一份页面产物及状态记录，目录发布继续使用`manuals/transactions/`。失败结果移到同一私密记录内，旧页面恢复；不自动删除历史副本。它们会占用额外本地空间，本阶段没有增加自动清理或永久删除入口。若状态显示准备中或构建中而原进程已经结束，应先核对前后版本和操作回执，不能直接重复发布。

完整业务备份应在停止对应服务、确认没有上传或生成任务仍在写入后进行。按实际运行配置成套保留以下内容，不能只备份Git代码或公开网页：

- 账号目录及其中的SQLite数据库、私密投稿目录；后者包含源PDF、JPEG、生成任务、提交版本、交接和操作回执。
- 本地管理的目录、档案草稿、历史、回收区、操作记录及其他既有私密业务数据。默认在`local-admin/`的相应目录；如果使用环境变量改过位置，以实际目录为准。
- `archive-data/`、`public-assets/inbox/`中的发布候选副本，`site/public/archive/`中的发布副本、网站生成数据、其他现有发布资源及一份可恢复的页面产物。这里均为网站发布层，不包括项目之外的原始档案主库。
- 本机PDF配置单独私密保留。换电脑或恢复到不同位置后，应重新核对工具固定版本、文件摘要、配置和Windows隔离能力；不把旧绝对路径直接当成新机器可用配置。工具未通过核验时暂停新生成和发布，历史仍按留存规则读取。

恢复先在独立临时目录中进行，核对文件完整性、账号归属、源文件及整册摘要、版本和回执，再确认没有中断操作会自动重放。不要把私密备份放入`site/public/`、`site/dist/`或公开部署包。本次已在关闭合成服务和数据库连接后完整复制测试环境，逐文件核对，并恢复账号、会话、200页来源与页面、上传／生成／提交回执；没有备份、读取或恢复真实账号与真实投稿。
