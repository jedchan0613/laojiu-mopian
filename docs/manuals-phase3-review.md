# 说明书专栏第三阶段验收与操作说明

日期：2026年11月10日  
状态：第二阶段外观自检补齐；第三阶段本地维护与发布检查完成。  
范围：本地功能、隔离样例验收及发布规则衔接。本次没有真实说明书入站、服务器操作、提交、推送或部署。

## 一 怎样使用

1. 双击项目根目录的 `启动档案管理.cmd`。
2. 在工作台选择“说明书维护”，或访问 `http://127.0.0.1:4173/admin/manuals.html`。
3. 先在“品牌”填写品牌名称、核定别名及依据；再在“型号”填写所属品牌、完整型号、物件名称、品类及型号依据。
4. 在“说明书”选择明确适用型号，填写用途、语言、地区、版本、完整程度及适用依据。
5. 官方索引填写厂家入口、最近核对日期、可用状态和核对依据。程序不自动访问或推断网址是否官方，维护者须实际核对。
6. 站内阅读选择已审核馆藏，将已公开附件加入页序，填写纸面页码、阅读目录与展示依据。新图片和替换图片先在既有档案管理中按待入站、隐私检查、人工批准、构建流程处理。
7. 点击“保存目录草稿”，再打开“预览已保存资料”。保存不改变正式目录。
8. 点击“发布前检查”，处理列出的问题；核对本次目录及移除影响后，逐项人工确认，生成本地正式目录。

如果原来的管理服务仍在运行，先保存其他管理页面的工作，关闭旧启动窗口，再重新双击启动入口。程序不会自动停止其他服务或放弃未保存工作。

本阶段按整个目录保存、检查和发布。品牌与型号尚未关联说明书时不会进入公开投影；未撤下说明书中存在缺项时，会阻止本次发布。需要更正已发布资料时，先编辑和保存新草稿；旧正式版本保留到本次检查与构建成功。

## 二 已实现内容

| 功能 | 实际行为 |
| --- | --- |
| 目录维护 | 品牌、型号、文档版本分别编辑；支持品牌与型号别名、多型号适用、多语言、多来源 |
| 草稿隔离 | 草稿保存到私密维护目录，不直接修改网站展示数据；允许保存待补充内容 |
| 预览 | 已保存资料可在独立的本机页面核对；支持翻页、页序、目录、放大和单页重试 |
| 过期预览 | 草稿更新后，旧预览地址明确失效，须从维护页重新打开 |
| 页序与目录 | 只能选择本档案已公开附件；移动或移除页面后清空旧目录，避免跳转错页；原图片不删除 |
| 来源维护 | 记录HTTPS网址、名称、可用状态、核对日期和私密依据；不可用来源不提供假阅读入口 |
| 发布检查 | 核对关系、必填项、型号与别名冲突、重复版本、页序、缺页、来源、附件和展示依据 |
| 人工确认 | 清单绑定当前目录、关联档案和图片摘要；缺少确认、目录变更或图片变化时须重新核对 |
| 并发保护 | 复用现有写入队列、操作编号和版本检查；旧页面不能覆盖新版本，重复请求不重复执行 |
| 正式构建 | 生成白名单公开投影后执行既有正式构建；成功后才采用新目录 |
| 失败回退 | 保留发布前目录、页面和状态；构建失败恢复上次结果，草稿继续保留 |
| 撤下 | 说明撤下影响并填写原因后，重建目录；当前草稿中的同一条目标记撤下，其他草稿保留 |
| 历史恢复 | 保存修改前草稿、发布前及撤下前版本；恢复只生成草稿，已有草稿先备份 |
| 档案撤下联动 | 关联档案不再满足ACT/G/U3时，专栏不再输出对应题名、简介、型号与阅读入口 |

撤下说明书只调整专栏引用，不删除正式档案或附件。需要回收旧图片时，仍由原档案管理的正式发布与回收流程处理，专栏不复制一套图片管理机制。

## 三 数据与公开范围

- `local-admin/manuals/state.json` 保存已审目录和独立草稿；`history/` 保存目录历史，`transactions/` 保存发布前状态与页面备份。上述内容全部私密、受Git忽略规则保护。
- 公开输入为 `site/src/data/generated/manuals-catalog.json`，只保留明确允许展示的字段，不含依据、审核备注、账号或联系方式。
- 本地管理页面、脚本、草稿和历史不进入 `site/dist/`；正式构建检查会阻止额外私密文件混入说明书页面目录。
- 管理接口和页面仅在本机模式开放；线上模式拒绝该入口，包括编码和大小写变体。错误配置把说明书私密数据放入公开目录时，服务停止启动。
- 沿用正式档案的永久编号、`core`、`metadata`、`public_view` 和既有下载规则；没有新增正式类型或分类代码。
- 阅读只关联已公开的OTH/RPR通用结构档案，附件必须属于本档案、真实存在、格式匹配且为JPEG、PNG或WebP；不接收主档或任意外部路径。
- 历史恢复、预览和日常编辑不会修改原档案；关联档案本身的隐私、权利或公开状态变化后，旧人工确认不再适用。

网站数据同步会重新生成已审目录。没有私密维护记录的新应用版本会核验并保留继承的公开投影，避免用空目录覆盖既有资料；部署脚本只继承这个公开输入，排除整个私密维护目录。本次只修改本地脚本，没有执行部署。

发布前页面备份会占用本机磁盘。为保持可恢复，本阶段不自动删除历史、事务备份或图片。若发布过程被强制中断，保留日志和前后版本并暂停写入，等待核对，不自动猜测成功或重放。
