## 本阶段的结果

保存期间继续输入不会被旧响应覆盖；保存状态持续显示在状态栏和底部操作栏，失败、断网、登录失效、版本冲突和"结果未知"都有文字说明与可执行的下一步。离开编辑页可选"保存草稿并继续"。浏览器返回键纳入同样的处理。响应丢失时提供"核对保存结果"按钮，查询服务器操作收据后决定解除还是维持停止。

图片逐张显示"已选择，未保存 / 已暂存 / 已保存到草稿 / 上传失败"；某张失败只重试失败的那张，已暂存令牌可继续使用；服务重启后仍有效的暂存图片从操作收据恢复，失效令牌明确提示重新上传。全部在隔离副本上用合成资料验证，未触碰真实档案。

## 已落实的能力

- **保存快照与编辑序号。** 每次保存固定内容快照；保存期间的新输入由下一次保存确认，旧响应只更新版本信息，不覆盖表单、不清除未保存标记、不标成"全部已保存"。自动保存沿用本次编辑会话的操作编号，失败重试不重复分配编号。
- **持续保存状态。** 状态栏覆盖未保存、保存中、已保存（本机/线上草稿 + 时间）、待传图片、失败、断网、登录失效、版本冲突、结果未知九种状态，均给出下一步动作；不再只靠转瞬提示。
- **自动保存节奏。** 纯文字停止输入约 5 秒保存；连续编辑约 30 秒保存完整快照；中文输入法组词期间（compositionstart/end）不打断；有待上传新图/替换图时暂停自动保存并提示"有图片待上传，请保存草稿"；自动保存不遮挡页面，草稿最低条件不齐时不反复请求。
- **离开三选与返回键。** 返回列表、切换档案、新建、切换工作区、跳转其他管理页统一为"保存草稿并继续 / 继续编辑 / 放弃本次未保存修改"；保存成功后才执行离开。浏览器返回键通过历史记录布防纳入同样处理，`beforeunload` 保留兜底。
- **断网与登录失效。** 网络失败归类为断网持续状态；401/403/非 JSON 登录页识别为登录失效，显示"重新登录"按钮（同一浏览器另开登录页，原页保留）；网络恢复只作为重新核对的信号，回前台先核对版本再继续。
- **结果未知核对。** 写入响应丢失时页面进入待核对并阻止重复提交；点"核对保存结果"查询服务端收据：已成功则解除并提示以服务器草稿为准，未完成则解除允许重试，进行中/待人工核对则维持停止。
- **图片逐张状态与恢复。** 服务端新增暂存令牌状态查询（`/api/staged-uploads/status`：available / consumed / missing）；保存失败时已暂存令牌保留、已复制的图片记录首次写入结果供重试核对；服务重启后从操作收据 + 暂存文件恢复仍有效的令牌（字节级 SHA-256 与格式复核），失效的明确报错。保存成功才结算暂存图片。

## 行为边界（未变化）

隐私确认绑定图文版本、发布中断核对、变更对照完善属于第四阶段；安卓真机验证属于第五阶段。`operations/` 收据字段白名单、容量上限、待核对暂停写入等第二阶段约定全部保留；本阶段仅新增只读的收据列举与令牌状态查询接口。未新增任何 Node.js 依赖。

## 本机样例与停止点

样例：<http://127.0.0.1:4195/admin/>。只使用合成资料，只在这台电脑访问。启动方式：

```powershell
node local-admin/mobile-preview.mjs --stage=3
```

构建与校验：

```powershell
node local-admin/mobile-preview.mjs --stage=3 --build
node local-admin/mobile-preview.mjs --stage=3 --verify-protected
```

本阶段未改动真实档案、未操作项目外原始主库、未推送、未部署、未连接生产服务器。浏览器演练与安卓真机差异说明：本机演练用 Edge 无头 + 390×844 视口模拟，未覆盖真实输入法、软键盘、锁屏与相册选择；这些留待第五阶段真机验收。

第三阶段到此完成。手机纵向变更对照、待补项定位、隐私确认绑定图文版本、发布结果核对与完整构建门禁属于第四阶段；线上部署与安卓真机试用属于第五阶段，均须用户另行明确指定。
