# 说明书专栏第二阶段验收记录

日期：2026年11月10日  
范围：本地查询与阅读  
依据：[第一阶段详细设计](manuals-phase1-design.md)、[演示资料与Q01至Q24场景](manuals-phase1-samples.md)、[开发阶段计划](manuals-development-plan.md)。

本阶段已在现有Astro网站中实现说明书查询、筛选、文档详情、逐页阅读、官方来源入口与型号帮助。使用显式开启的本地虚构资料完成验收，正式目录尚未加入真实说明书。

## 一 已实现内容

| 功能 | 实际行为 |
| --- | --- |
| 品牌与型号查询 | 支持品牌别名、大小写与全半角；保留型号后缀，区分跨品牌同名型号 |
| 相关结果 | 准确型号优先，片段、格式近似与关键词结果分别提示，不把0和O互换 |
| 筛选 | 品类、品牌、语言，以及用途、地区、年代、完整程度和获取方式 |
| 型号分组与统计 | 每个型号集中列文档；型号数与去重后的文档版本数分别计算 |
| 查询网址与返回 | 筛选写入网址；进入详情、切换相关文档后返回可保留条件和位置 |
| 文档详情 | 显示明确适用型号、版本、地区、语言、完整程度、缺页与来源状态 |
| 逐页阅读 | 上下页、页序选择、目录跳转、放大、纸面页码及无效页码恢复 |
| 图像加载 | 使用同一张主图切换，只预取紧邻下一页；失败时保留页码并提供重试 |
| 官方来源 | 仅核定的HTTPS网址生成外站链接，保留外站隔离设置；失效来源不提供假阅读入口 |
| 异常状态 | 无结果、索引加载失败、来源不可用与已撤下资料分别处理 |
| 网站衔接 | 导航与中文首页增加说明书入口，其他语言导航明确指向中文专栏 |
| 本地启动 | 提供双击启动入口，复用现有Astro后台预览，不替换其他运行中的预览 |

官方索引样例仍使用 `example.invalid`。演示按钮说明真实入口将如何工作，不访问虚构厂商网址；正式资料将使用经核定的真实来源。

## 二 怎样查看

在项目根目录双击 **启动说明书本地预览.cmd**，启动后会打开说明书库。默认使用本机4236端口；若Astro选择其他可用端口，启动器使用它实际返回的地址。

这个入口展示第一阶段的2个虚构品牌、6个型号和9份状态样例。其中公开可用列表为5个型号、6份独立文档版本，另有1份来源失效资料；草稿与已撤下样例不出现在查询中。

它与日常档案管理的4173入口分开，不连接真实投稿或账号业务。本阶段不要求维护者手工修改JSON来发布真实说明书。

若本项目已有其他Astro预览，启动器会先核实是否开启说明书演示；模式不同则提示并保留原服务，不自动关闭或强制替换。

## 三 数据与隐私边界

- 普通正式构建只读取独立的说明书发布投影；文件未建立时先显示空目录。
- 本机开发模式只有显式设置 `LJM_MANUALS_DEMO=1` 才读取 `samples/manuals-demo/`，正式构建拒绝该演示开关。
- 演示图像只在本地演示端点生成，正常构建不生成其详情或图片，并有额外检查阻断样例进入正式产物。
- 公开查询索引按字段白名单生成，不含图片路径、下载地址、账号、联系方式或审核记录。
- 馆藏阅读仅引用本档案已公开附件，并检查现有ACT、G、U3及类型与schema关系；目录不能覆盖下载政策。
- 没有更改正式档案、原有发布源图片、永久编号、正式规范或项目外档案主库。

`site/src/data/generated/manuals-catalog.json` 是未来经审核生成的发布输入，已加入忽略规则。当前未创建真实目录内容。读取器要求发布状态与审定标记，关联图片另需展示依据；这些只描述可信发布输入的约束，不能替代第三阶段的人工审核、历史和正式发布流程。

18项跳过项依赖Linux文件锁、挂载隔离、Caddy或POSIX线上切换环境，按原有测试条件在Windows跳过。本阶段没有执行线上服务与部署验收。

初次验收时截图接口不可用，仅完成交互、页面结构和尺寸检查。2026年11月10日按用户后续指令补齐截图自检：查询、阅读、官方来源、缺页、来源失效及型号帮助，在320、390、1280像素下取得18组实际页面截图并检查。手机页码选择框改为独占一行，避免印刷页码被截断；新增键盘焦点提示。截图保存在 `outputs/manuals-phase3/`，不是第一阶段原型截图。后续记录见[第三阶段验收](manuals-phase3-review.md)。

本机证据保存在 `outputs/manuals-phase2/`，包括测试日志、浏览器检查、HTTP检查、构建日志与受保护文件快照，不进入公开部署。
