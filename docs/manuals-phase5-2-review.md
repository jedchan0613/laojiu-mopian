## 怎样使用

1. 保存其他工作的进度，关闭旧版管理服务的启动窗口，再双击项目根目录的 `启动档案管理.cmd`。
2. 打开 `http://127.0.0.1:4173/manuals/contribute/`，登录后新建文字草稿，或从“我的投稿”继续已有说明书。上传前先保存文字信息。
3. 在“05 说明书页面”逐张检查候选图片，勾选副本筛选确认，选择本批文件，再点击“开始上传”。图片不会因选择文件而自动上传。
4. 系统逐张保存，可选择“本页完成后暂停”，然后继续同一批。关闭页面后，已完成的页面仍在草稿中；重新打开后选择剩余文件继续，不必重传已保存部分。
5. 在已保存页面中上移、下移，或直接修改“页序”并离开输入框，把页面移动到指定位置。可填写印刷页码与本页说明，随后点击“保存页序与页码”。
6. “替换此页”先选择一张新副本，再点击开始上传。成功前保留原页面，成功后沿用原来的位置、页面身份、印刷页码及说明。移出本册需确认；旧图片不永久删除。
7. 点击“预览整册”，使用上一页、下一页和跳页查看，可在适宽与原尺寸之间切换。未保存的页序会明确标注，不把尚在上传队列中的文件当成已保存页面。

独立4236端口的说明书样例预览不提供账号保存。普通档案投稿沿用原有八图流程，说明书长册从专用入口登记。

## 容量与保存方式

| 范围 | 当前限制与处理 |
| --- | --- |
| 文件类型 | JPG、PNG、WebP筛选副本；不接收PDF、TIFF、RAW、SVG或动画/多页图 |
| 单张 | 选择的副本最多5 MB，真实解码后按原有规则校正方向、最长边不超过2400像素、生成JPEG并去除内嵌元数据 |
| 每批选择 | 最多50张，按所选顺序逐张发送，每个请求只有一张；用户可随后调整页序 |
| 单次图片请求 | 最多6 MB，给单张图片和表单信息预留空间；普通八图投稿请求限制保持原样 |
| 每册 | 当前页数最多200页；私密副本总计最多100 MB、1000份，含替换、移出和异常中断留下的副本 |
| 账号 | 沿用200 MB总额及20件未提交草稿配额，没有另增一套账号额度 |
| 暂存区 | 沿用现有共享私密收件区总额，新增上传核对实际磁盘副本占用，包含保留副本 |
| 并发 | 本页顺序上传，每账号同时一张，服务最多同时处理两张；真正落盘继续使用账号、收件区及草稿写入锁 |
| 访问频率 | 已登录说明书请求使用单独的账号/IP双限额，每10分钟最多800次；普通账号、注册与八图投稿的原有限流不变 |

这是逐页续传，不是单个大文件的分块传输。网络中断后整张重试本次操作；已保存的其他页不重传。文件队列只留在当前页面内存中，不写入浏览器持久存储；关闭页面后需要重新选择剩余文件。

## 私密与版本保护

复用现有账号、私密收件区、图片签名检查、真实解码和重编码，不新增依赖、服务或数据库。保存的图片不会进入 `public-assets/`、公开目录、说明书搜索索引或正式档案；原始选择文件不会被改写。

当前图片继续放在该账号投稿的私密目录，通过归属账号的接口读取，禁止缓存并限制同源使用。替换、移出和未引用的旧副本不能通过当前页面图片入口读取，文件仍保留并计入容量。页面身份仅用于账号草稿中的页序，不替代或新增正式LJM档案编号。

每次上传、调序和移出都有独立操作凭证及草稿版本。服务端保留最近200次私密操作回执，重试先核对是否已经保存；同一凭证内容改变、旧版本或伪造页序会被拒绝。图片先写入私密目录，再原子替换记录；若在两步之间中断，重试会核对同一副本，未完成记录不会成为可阅读页面。保留副本也占用容量，不能通过反复替换规避限制。

文字保存会保留已有整册，图片操作不覆盖品牌、型号或授权意向。界面在上传或页序有未保存修改时限制交叉修改；版本冲突会保留当前填写。来源、登录与专用请求标记、账号归属、暂停写入开关等保护均保留。账号详情不下发内部回执指纹、旧副本档案或管理员备注。

副本筛选确认仅用于本次私密图片处理，不替代人工权利、人物与隐私审核。记录仍为草稿，原有公开、权利与隐私授权确认保持未确认，不能通过普通编辑或送审入口提前进入审核、转档案或公开。
