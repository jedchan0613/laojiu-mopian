# 日语、韩语及繁体中文验收说明

默认入口仍是简体中文 `/`。语言菜单共六项：简体中文、English、ไทย、日本語、한국어、繁體中文；新增路径为 `/ja/`、`/ko/`、`/zh-hant/`，繁体语言标识为 `zh-Hant`。菜单在手机上可滚动，保留当前选中项，支持键盘、Escape 和外部点击关闭。切换保留当前档案、筛选、搜索词与锚点。

三种语言各提供当前生产网站164件公开档案的独立译文及299条图片说明。永久编号、图片、分类代码、归册关系和公开权限共用原资料；不创建另一份档案身份。译文保留“推测、待核、不明”等限定，原件转录和原文日期字段保持原文，不把翻译冒充原件。实物相册与“明的家书”网站主题选览仍明确区分。

繁体文字使用生成时的固定转换表，并校正“關於、聯繫、標籤、複製”等词语；网页运行时只翻译固定界面，不转换访客昵称、投稿、人工回复或原件文字。日语、韩语使用固定译文。所有语言日期均使用公历。字体采用设备已有的相应语言字体，不增加外部字体服务。

译文维护入口可独立选择英、泰、日、韩、繁体。草稿、审核版本、历史按语言隔离；来源变化按字段失效，继续执行ACT/G/U3、字段白名单、图片路径与构建门禁。未知语言参数拒绝处理。六语言检索采用同一组有效文字，编号、筛选代码、图片和件数一致。账号偏好、固定提示及既有三类通知邮件支持新增语言；邮件仅通过文件模拟测试，未发送真实邮件。
