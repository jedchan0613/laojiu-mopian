# 说明书品牌与品类浏览页面验收

日期：2026年11月10日  
状态：本轮页面功能完成，未上线。  
依据：用户要求暂缓本地维护与资料整理，优先推进后续页面功能；本轮范围为品牌、品类浏览和既有查询、阅读页面的衔接。

## 一 怎样查看

双击项目根目录的 `启动说明书本地预览.cmd`，在说明书库中选择“按品牌浏览”或“按品类浏览”。继续选择品牌或品类，可以浏览型号、选择说明书并进入阅读。预览沿用虚构样例，资料页有明确演示标识。

本地维护功能保留，本轮不要求先整理真实说明书或使用维护入口。正式目录为空时，品牌与品类入口显示资料整理提示；不会用演示数据填充正式网站。

## 二 完成内容

| 页面或功能 | 行为 |
| --- | --- |
| 品牌目录 `/manuals/brands/` | 显示已收录品牌、核定别名、可用型号与去重文档数量；来源失效数量单独说明 |
| 品牌资料页 | 列出该品牌的型号与文档，支持在当前品牌中查询，按品类缩小范围 |
| 品类目录 `/manuals/categories/` | 显示有公开资料的品类、覆盖品牌、可用型号和独立文档数量 |
| 品类资料页 | 列出该品类的品牌和型号，支持当前品类内查询及按品牌缩小范围 |
| 栏目导航 | 查询、品牌、品类和型号帮助互通；手机下为两列可点按导航 |
| 搜索与详情衔接 | 查询结果中的品牌可打开品牌资料页；详情可继续浏览相关品牌和品类 |
| 返回原位置 | 从浏览页打开资料后，可返回原品牌或品类及原型号；切换相关文档后仍保留返回目标 |
| 来源失效 | 可用资料与来源失效分别展示，不把失效来源算作可阅读文档 |
| 空目录 | 显示整理提示和可用的查询、帮助入口；没有已审资料的品牌或品类不生成空详情页 |

一份手册适用多个型号时，只算一份独立文档；若跨品类适用，会在相应品类分别显示，因此各品类数量不能直接相加作为全库数量。品牌地址使用稳定的查询目录标识，不依赖显示名称，也不占用正式档案永久编号。

## 三 实现与公开边界

复用现有Astro、公开投影和查询规则，没有增加依赖、数据库、服务或维护入口。新页面不读取草稿、依据、历史、账号或项目外主档。

只有现行公开投影中实际有资料的品牌或品类才生成详情。草稿、撤下资料以及失去公开条件的关联档案不会由新页面重新展示。目录首页在没有资料时禁止搜索引擎收录；演示页面始终禁止收录，正式构建仍拒绝演示资料。

详情返回地址只允许说明书查询及明确的品牌、品类路径，过滤额外参数，只保留规范的型号锚点；不能返回站外或管理入口。构建检查除原有门禁外，会核对品牌、品类详情是否与已审索引一致，拦截漏页、额外空详情和私密文件。
