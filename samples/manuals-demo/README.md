# 说明书专栏本地演示资料

全部沿用第一阶段的虚构样例：2个品牌、6个型号、9份文档状态，不代表真实库存，也不用于设备操作。

仅在本机开发模式显式设置 `LJM_MANUALS_DEMO=1` 时读取。正式构建拒绝此开关，普通构建不读取本目录，也不生成演示图片或详情。演示页面有醒目标识且禁止搜索引擎收录。

样例中的官方网址使用 `example.invalid`，页面只解释入口，不访问外站。图像由本地演示端点生成的文字示意组成，不使用真实扫描件、主档、人物或私人信息。

本目录不是入站区，不能将真实资料放入。真实发布图片仍执行 `public-assets/inbox/` 与现有人工审核流程。
